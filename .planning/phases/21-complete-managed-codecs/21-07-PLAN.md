  <action>
The magnitude refinement pass has asymmetric skipping logic:

**Encoder (lines 314-321):**
```csharp
int msbOfSample = FindMsbPositionSingle(magnitude);
if (msbOfSample == bitplane)
{
    // This was just made significant at this bitplane
    continue;
}
```

**Decoder (lines 222-228):**
```csharp
int higherBits = _magnitudeState![idx] >> (bitplane + 1);
if (higherBits == 0)
{
    // Made significant at this bitplane, not refined yet
    continue;
}
```

The encoder checks if the sample's MSB equals the current bitplane.
The decoder checks if there are magnitude bits above the current bitplane.

**The fix:**
Both encoder and decoder should use the same logic: track when each sample became significant and skip refinement if it became significant at the current bitplane.

1. In EbcotEncoder: Change magnitude refinement to track "first significant bitplane" per sample, not recalculate from coefficient value. Add `_firstSignificantBitplane` array initialized to -1, set when sample becomes significant.

2. In EbcotDecoder: Use the same tracking - when a sample becomes significant in any pass, record the bitplane. In refinement pass, skip if `_firstSignificantBitplane[idx] == bitplane`.

Alternatively (simpler fix): Make the decoder match the encoder's logic by computing MSB from accumulated magnitude state:
```csharp
// In decoder refinement pass:
int magnitude = _magnitudeState![idx];
int msbOfSample = magnitude > 0 ? FindMsbPosition(magnitude) : -1;
if (msbOfSample == bitplane)
{
    continue; // Just became significant this bitplane
}
```

Choose the simpler fix that aligns decoder with encoder.

```csharp
[TestFixture]
public class EbcotRoundtripTests
{
    [Test]
    public void SimpleGradient_RoundtripsCorrectly()
    {
        using var encoder = new EbcotEncoder();
        var decoder = new EbcotDecoder();

        int[] input = new int[64]; // 8x8
        for (int i = 0; i < 64; i++)
            input[i] = i - 32; // Range -32 to 31

        var encoded = encoder.EncodeCodeBlock(input, 8, 8, subbandType: 0);
        var decoded = decoder.DecodeCodeBlock(
            encoded.Data.Span,
            encoded.NumPasses,
            8, 8,
            encoded.MsbPosition,
            subbandType: 0);

        Assert.That(decoded, Is.EqualTo(input));
    }
}
```
