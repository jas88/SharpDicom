  <action>
Create the HT (High Throughput) block coder as defined in ISO/IEC 15444-15:

**HtBitWriter.cs** - VLC bit I/O for encoding:
- ref struct HtBitWriter with internal buffer
- WriteBits(int value, int numBits) - write variable-length codes
- WriteVlc(int value) - write using HT VLC tables
- Flush() - finalize output
- No MQ arithmetic coding (key HT simplification over EBCOT)

**HtBitReader.cs** - VLC bit I/O for decoding:
- ref struct HtBitReader with input span
- ReadBits(int numBits) - read variable-length codes
- ReadVlc() - read using HT VLC tables
- PeekBits(int numBits) - lookahead without consuming

**HtBlockCoder.cs** - Main HT algorithm (ISO/IEC 15444-15 Section 7):
- static class HtBlockCoder
- EncodeBlock(int[] coefficients, int width, int height, int msbPosition) -> CodeBlockData
- DecodeBlock(ReadOnlySpan<byte> data, int width, int height, int msbPosition) -> int[]

HT algorithm key differences from EBCOT:
1. **Fixed VLC tables** instead of adaptive MQ coder (much faster)
2. **HT sets** - predetermined significance propagation patterns
3. **Simplified pass structure** - magnitude refinement + sign + cleanup
4. **No context adaptation** during coding (contexts fixed per pass)

Implementation based on OpenJPH reference algorithm:
- Significance pass uses VLC for magnitude
- Sign coding uses fixed context
- Cleanup pass with optimized bit manipulation

Key implementation details:
- Code-blocks still 64x64 (same as EBCOT)
- Output format compatible with standard J2K packet structure
- CAP marker indicates HT capability (already implemented in Htj2kCodec.cs)
