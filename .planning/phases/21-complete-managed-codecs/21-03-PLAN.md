**Dwt53.cs optimization:**
Optimize the 5/3 wavelet lifting steps with SIMD:

```csharp
// Before (scalar):
for (int i = 1; i < length - 1; i += 2)
    odd[i/2] = samples[i] - ((samples[i-1] + samples[i+1]) >> 1);

// After (SIMD for 4 values at once when length >= 8):
if (Vector128.IsHardwareAccelerated && length >= 8)
{
    // Process 4 odd samples at once
    var left = Vector128.LoadUnsafe(ref samples[i-1]);
    var center = Vector128.LoadUnsafe(ref samples[i]);
    var right = Vector128.LoadUnsafe(ref samples[i+1]);
    var avg = (left + right) >> 1;
    var result = center - avg;
    result.StoreUnsafe(ref odd[i/2]);
}
```

**Auto-parallel in JpegLsCodec.cs:**
```csharp
// For images > 512x512, use parallel encoding per line/stripe
if (info.Columns * info.Rows > 262144) // 512x512 threshold
{
    // JPEG-LS can parallelize by encoding different components
    // or by splitting image into horizontal stripes
    Parallel.ForEach(stripes, stripe => EncodeStripe(stripe, ...));
}
```

**Auto-parallel in Htj2kCodec.cs:**
```csharp
// For images > 512x512, use parallel code-block encoding
if (info.Columns * info.Rows > 262144)
{
    // HTJ2K naturally parallelizes at code-block level
    Parallel.ForEach(codeBlocks, block => HtBlockCoder.EncodeBlock(block, ...));
}
```

Parallel considerations:
- Don't parallelize small images (overhead > benefit)
- Use Environment.ProcessorCount for thread count
- Use partitioning to avoid false sharing
- Ensure thread-local state (context arrays, bit writers)
