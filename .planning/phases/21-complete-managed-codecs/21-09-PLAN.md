Based on Task 2 results and J2kPipelineTests, debug the decoder packet parsing.

**Specific issues identified in 21-08 investigation:**

1. **J2kDecoder doesn't update dataOffset when processing multi-component images**:
   - Look for packet parsing loop in `DecodeTile()` method
   - Verify that after reading each packet, `dataOffset` is incremented by packet size
   - This is critical for multi-component images where each component has its own packet

2. **J2kDecoder may not correctly parse packet boundaries**:
   - Verify that tier-2 packet parsing correctly handles:
     - Empty packets (zero-length code-blocks)
     - Multiple code-blocks per packet
     - Packet header parsing (SOP/EPH markers if present)

**Investigation steps:**

1. Run `Decoder_ParsesMultiComponentPackets` test:
   - Create a simple 3-component (RGB) encoded stream
   - Verify decoder correctly extracts all 3 components
   - Add logging to show dataOffset before/after each packet

2. Run `DWT_EBCOT_Tier2_Roundtrip_SingleComponent` test:
   - If encoder passes but full roundtrip fails, issue is in decoder
   - Compare decoded coefficients to encoded coefficients
   - Identify which stage loses data

**Common decoder integration issues to check:**

1. **Packet data offset tracking**: After `PacketDecoder.ReadPacket()`, the decoder must advance its read position by the packet size. Check:
   ```csharp
   // WRONG: Uses same offset for all components
   for (int c = 0; c < components; c++) {
       ReadPacket(data.Slice(offset), ...);
   }

   // RIGHT: Advances offset after each packet
   int offset = 0;
   for (int c = 0; c < components; c++) {
       int packetSize = ReadPacket(data.Slice(offset), ...);
       offset += packetSize;
   }
   ```

2. **Code-block extraction**: Verify that decoded code-block data is copied to the correct position in the coefficient buffer for IDWT.

3. **Multi-resolution handling**: Ensure that code-blocks from different resolution levels are assembled correctly.

**Fix approach:**
- Add offset tracking assertions (offset should increase, not stay constant)
- Add coefficient buffer checks (should be non-zero after decoding)
- Verify buffer slicing bounds are correct
- Check for missing return values (packet size not being used)

After fixing, verify all J2kPipelineTests pass.
