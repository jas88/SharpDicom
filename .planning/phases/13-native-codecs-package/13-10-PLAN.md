<task type="auto">
  <name>Task 1: Create pre-configured vendor headers for cross-compilation</name>
  <files>
    native/vendor/libjpeg-turbo/jconfig.h
    native/vendor/libjpeg-turbo/jconfigint.h
    native/vendor/openjpeg/opj_config.h
    native/vendor/openjpeg/opj_config_private.h
  </files>
  <action>
    Create pre-configured header files that would normally be generated by CMake. This avoids the CMake dependency for cross-compilation.

    **For libjpeg-turbo (jconfig.h):**
    - Define standard types: HAVE_STDDEF_H, HAVE_STDLIB_H
    - Set BITS_IN_JSAMPLE to 8 (standard 8-bit JPEG)
    - Define JPEG_LIB_VERSION (80 for libjpeg 8 API compatibility)
    - Enable SIMD: HAVE_SIMD (will be detected at runtime)
    - Do NOT define WITH_12BIT (12-bit is optional, complex to support)

    **For libjpeg-turbo (jconfigint.h):**
    - Define BUILD constant and VERSION strings
    - Define memory alignment (16 bytes for SSE)
    - Platform-specific thread-local storage macros

    **For OpenJPEG (opj_config.h):**
    - Define OPJ_VERSION_MAJOR, OPJ_VERSION_MINOR, OPJ_VERSION_BUILD
    - Define OPJ_HAVE_STDINT_H, OPJ_HAVE_INTTYPES_H
    - Set OPJ_USE_THREAD to 0 (single-threaded for simplicity)
    - Define OPJ_STATIC for static linking

    **For OpenJPEG (opj_config_private.h):**
    - Define internal configuration
    - Disable big-endian (most platforms are little-endian)
    - Set alignment requirements

    NOTE: These headers are platform-agnostic. Platform-specific detection happens at runtime in the wrapper code.

    Create .gitignore in vendor directories to ignore downloaded source but keep our config headers.
  </action>
  <verify>
    Check files exist and contain expected defines:
    - `grep JPEG_LIB_VERSION native/vendor/libjpeg-turbo/jconfig.h`
    - `grep OPJ_VERSION_MAJOR native/vendor/openjpeg/opj_config.h`
  </verify>
  <done>
    Pre-configured headers exist for libjpeg-turbo and OpenJPEG, enabling Zig-only cross-compilation without CMake.
  </done>
