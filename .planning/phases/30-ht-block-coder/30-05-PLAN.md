<objective>
Implement the SigProp and MagRef refinement passes and assemble the complete HtBlockEncoder/Decoder that combines all three passes into HT Sets.

Purpose: The Cleanup pass (Plan 04) handles the primary coding. SigProp and MagRef are optional refinement passes that improve quality at higher bitrates. Together, they form an HT Set (Cleanup + SigProp + MagRef). A code-block can have 1-2 HT Sets (1-6 passes total). This plan completes the core HT algorithm and wraps it behind IBlockCoder for pipeline integration.

Output: HtSigProp, HtMagRef, HtBlockEncoder (IBlockCoder), HtBlockDecoder, and comprehensive roundtrip tests.
</objective>

  <action>
Create HtSigProp as a static class implementing the ITU-T T.814 Significance Propagation pass:

**Encode** `Encode(ReadOnlySpan<int> coefficients, ReadOnlySpan<byte> sigState, int width, int height, int subbandType)` returns `ReadOnlyMemory<byte>`:
- Processes samples that are NOT yet significant but have significant neighbors
- For each such sample: encodes a significance bit (is it now significant at this precision?)
- If newly significant: encodes sign bit and magnitude bits
- Uses a simple byte-aligned bitstream (not the three-stream VLC/MEL/MagSgn format)
- The sigState input comes from the Cleanup pass output

**Decode** `Decode(ReadOnlySpan<byte> data, Span<int> coefficients, Span<byte> sigState, int width, int height, int subbandType)`:
- Reverses the encoding: reads significance bits for candidate samples
- Updates sigState and coefficient values for newly significant samples

Create HtMagRef as a static class implementing the Magnitude Refinement pass:

**Encode** `Encode(ReadOnlySpan<int> coefficients, ReadOnlySpan<byte> sigState, int width, int height)` returns `ReadOnlyMemory<byte>`:
- Processes samples that ARE already significant
- For each significant sample: encodes the next magnitude bit (refining precision by one bitplane)
- Simple byte-aligned bitstream

**Decode** `Decode(ReadOnlySpan<byte> data, Span<int> coefficients, ReadOnlySpan<byte> sigState, int width, int height)`:
- Reads magnitude refinement bits and updates coefficient magnitudes

Both passes:
- Internal visibility, static classes
- [MethodImpl(MethodImplOptions.AggressiveInlining)] on inner loops
- Use stackalloc for small working buffers, ArrayPool for large

Create HtBlockEncoder implementing IBlockCoder:
- Static Instance property (singleton, stateless per locked decision)
- `EncodeBlock(ReadOnlySpan<int> coefficients, int width, int height, int subbandType, int msbPosition)`:
  1. Run HtCleanup.Encode for the Cleanup pass (always present)
  2. Optionally run HtSigProp.Encode (if precision target requires it)
  3. Optionally run HtMagRef.Encode (if precision target requires it)
  4. This forms HT Set 1. If a second set is needed for quality targets, repeat for remaining bitplanes (HT Set 2).
  5. Return CodeBlockData with pass data and pass count (1-6)
- Support for cleanup-only mode: when only 1 pass is needed (fast preset), skip SigProp and MagRef entirely
- Support for full quality mode: 2 HT Sets with all 3 passes each (6 passes total)
- Lossless mode always uses enough passes to represent all precision bits

Create HtBlockDecoder:
- Static Instance property
- `DecodeBlock(ReadOnlySpan<byte> data, int numPasses, Span<int> output, int width, int height, int msbPosition, int subbandType)`:
  1. Parse pass boundaries from the data (Cleanup segment, then optional SigProp/MagRef segments)
  2. Run HtCleanup.Decode for pass 1
  3. If numPasses > 1: run HtSigProp.Decode for pass 2
  4. If numPasses > 2: run HtMagRef.Decode for pass 3
  5. If numPasses > 3: second HT Set (passes 4-6)
  6. Reconstruct coefficient values

Create HtBlockCoderTests:

- Roundtrip full quality (3 passes): encode 1 HT Set, decode, verify lossless

- Compare IBlockCoder interface: HtBlockEncoder.Instance implements IBlockCoder correctly
- Various code-block sizes: 4x4, 16x16, 32x32, 64x64
- Various subband types: LL, LH, HL, HH
- Edge cases: all-zero block, single non-zero, maximum magnitude values
- FsCheck property test: random coefficients with random dimensions, roundtrip always lossless when using full passes
