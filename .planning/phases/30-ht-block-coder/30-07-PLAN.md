<objective>
Add the IProgressiveCodec interface for resolution-level decode and extend SIMD support to Vector256/512 for DWT and HT hot paths.

Purpose: IProgressiveCodec enables efficient thumbnail generation (decode only lowest resolution level) and DICOMweb byte-range support. SIMD expansion (Vector256 AVX2, Vector512 AVX-512) doubles/quadruples throughput of DWT transforms, which are a significant portion of encode/decode time. BMI2 PDEP/PEXT intrinsics accelerate VLC bit manipulation in the HT block coder.

Output: IProgressiveCodec implemented on Htj2kCodecBase, DWT upgraded to Vector256/512, SimdHelpers extended.
</objective>

```csharp
public interface IProgressiveCodec : IPixelDataCodec
{
    /// Returns the number of available resolution levels in the codestream.
    int GetResolutionLevels(DicomFragmentSequence fragments, int frameIndex);

    /// Decodes at the specified resolution level (0 = lowest/thumbnail, max = full).
    /// Output dimensions are imageWidth / 2^(maxLevel - level) by imageHeight / 2^(maxLevel - level).
    DecodeResult DecodeAtResolution(
        DicomFragmentSequence fragments,
        PixelDataInfo info,
        int frameIndex,
        int resolutionLevel,
        Memory<byte> destination);

    /// Gets the output dimensions for a specific resolution level.
    (int Width, int Height) GetResolutionDimensions(
        DicomFragmentSequence fragments,
        PixelDataInfo info,
        int frameIndex,
        int resolutionLevel);
}
```
