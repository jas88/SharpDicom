   var readerOptions = new DicomReaderOptions

     WARN   DICOM-007  (0008,0050) AccessionNumber: Trailing spaces in value
     INFO   DICOM-012  (0010,0010) PatientName: Leading space in component

             "code": "DICOM-003",
             "tag": "00100020",
             "keyword": "PatientID",
             "message": "Value exceeds maximum length (64 > 64 chars)"

       "totalErrors": 3,

**DicomFixer.cs** - static class with fix methods:

```csharp
public static class DicomFixer
{
    /// <summary>
    /// Applies all enabled fixes to a dataset, returning list of changes made.
    /// </summary>
    public static List<FixAction> Fix(DicomDataset dataset, FixOptions options)
    {
        var actions = new List<FixAction>();

        if (options.FixInvalidUids) FixInvalidUids(dataset, actions);
        if (options.FixInvalidDates) FixInvalidDates(dataset, actions);
        if (options.RemoveInvalidElements) RemoveInvalidElements(dataset, actions);
        if (options.FixCharacterEncoding) FixCharacterEncoding(dataset, actions);

        return actions;
    }
}
```

**Fix categories:**

1. **FixInvalidUids:** Iterate all UI VR elements. For each, get string value and check with UidGenerator.IsValidUid (or manual check: only digits and dots, max 64 chars, no leading zeros in components except "0" itself). If invalid: generate new UID via UidGenerator.GenerateUid(), replace element, record FixAction.

2. **FixInvalidDates:** Iterate all DA VR elements. Common issues to fix:
   - `YYYY.MM.DD` -> `YYYYMMDD` (strip dots/dashes/slashes)
   - `DD/MM/YYYY` or `MM/DD/YYYY` -> attempt to parse and reformat as `YYYYMMDD`
   - Truncated dates like `200401` -> leave as-is (valid DICOM date range)
   - Empty string -> leave as-is (valid for Type 2 elements)
   Record FixAction for each change.

3. **FixInvalidTimes:** Iterate all TM VR elements:
   - Strip non-numeric characters except `.`
   - Ensure format matches `HHMMSS.FFFFFF` pattern

4. **RemoveInvalidElements:** Run validation with Strict profile, collect Error-level issues. For each errored element, remove from dataset and record FixAction with description "Removed: {reason}".

5. **FixCharacterEncoding:** If SpecificCharacterSet (0008,0005) is missing but string elements contain non-ASCII bytes, add `ISO_IR 100` (Latin-1) as a sensible default. Record FixAction.

**FixOptions** - simple class:
```csharp
public class FixOptions
{
    public bool FixInvalidUids { get; init; } = true;
    public bool FixInvalidDates { get; init; } = true;
    public bool FixInvalidTimes { get; init; } = true;
    public bool RemoveInvalidElements { get; init; } = false; // opt-in, destructive
    public bool FixCharacterEncoding { get; init; } = true;
}
```

**FixCommand.cs** - static class with `public static Command Create()`:

**Arguments and Options:**
- `Argument<FileSystemInfo[]>("files", "DICOM files or directories to fix")` - required
- `Option<bool>("--dry-run", () => false, "Show what would change without modifying files")` with alias `-n`
- `Option<bool>("--force", () => false, "Overwrite original files instead of creating .fixed.dcm")` with alias `-F`
- `Option<string?>("--output-dir", "Write fixed files to a specific directory")` with alias `-o`
- `Option<bool>("--fix-uids", () => true, "Fix invalid UIDs")`
- `Option<bool>("--fix-dates", () => true, "Fix invalid dates and times")`
- `Option<bool>("--remove-invalid", () => false, "Remove elements that fail validation")`
- `Option<bool>("--fix-encoding", () => true, "Fix missing character set declarations")`
- `Option<string>("--format", () => "text", "Output format for changes: text, json")` with alias `-f`
- `Option<bool>("--continue-on-error", () => false, "Continue fixing remaining files after errors")`

**Handler logic (async):**

1. Enumerate files using FileEnumerator
2. For each file:
   a. Open with `DicomFile.OpenAsync(path, ct: ct)`
   b. Create FixOptions from command flags
   c. Call `DicomFixer.Fix(file.Dataset, fixOptions)` to get list of FixAction
   d. If dry-run: output changes to stdout, don't save
   e. If not dry-run and changes > 0:
      - Determine output path: `--output-dir/filename.dcm` > `original.fixed.dcm` > original (if `--force`)
      - Save via `file.SaveAsync(outputPath, ct: ct)`
3. **Text output format:**
   ```
   file.dcm: 3 fixes applied
     FIX  (0020,000D) StudyInstanceUID: Invalid UID replaced
       - Old: 1.2.3.4.5.06.7
       + New: 2.25.123456789012345678
     FIX  (0008,0020) StudyDate: Date reformatted
       - Old: 2024.01.15
       + New: 20240115
     FIX  (0008,0005) SpecificCharacterSet: Added missing character set
       + New: ISO_IR 100
   ```
4. **JSON output format:** Array of objects with file path, changes array, output path
5. **Summary** to stderr: "Fixed N files (M changes total), K files unchanged"
6. Return ExitCodes.Success if all processed, ExitCodes.RuntimeError on errors
