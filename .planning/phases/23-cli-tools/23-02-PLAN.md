  <action>
Create `DumpCommand.cs` as a static class with a `public static Command Create()` method that returns a configured `Command("dump", "Display DICOM file contents")`.

**Arguments and Options:**
- `Argument<FileSystemInfo[]>("files", "DICOM files or directories to dump")` - required, accepts multiple
- `Option<string>("--format", () => "text", "Output format: text, json, xml")` with alias `-f`
- `Option<int?>("--max-depth", "Maximum sequence nesting depth to display")` with alias `-d`
- `Option<bool>("--no-private", () => false, "Hide private tags")`
- `Option<bool>("--no-pixel", () => false, "Hide pixel data element")`
- `Option<string?>("--tag-filter", "Only show specific tag (e.g., 00100010)")` with alias `-t`

**Handler logic (async, receives ParseResult + CancellationToken):**

1. Resolve output format from: explicit `--format` flag > `SHARPDCM_OUTPUT_FORMAT` env var > config file > "text" default
2. Create appropriate IOutputFormatter (TextFormatter, JsonFormatter, XmlFormatter based on format string)
3. Enumerate files using `FileEnumerator.EnumerateFiles(files)`
4. For multiple files, use ProgressReporter on stderr
5. For each file:
   a. `await DicomFile.OpenAsync(path, ct: ct)` with try/catch for DicomFileException and IOException
   b. On error: write error to stderr, if `--continue-on-error` continue, otherwise return ExitCodes.RuntimeError
   c. Call `formatter.WriteFileHeader(path, Console.Out)`
   d. Iterate `file.Dataset` (which implements IEnumerable<IDicomElement>):
      - Skip private tags if `--no-private`
      - Skip pixel data tag (7FE0,0010) if `--no-pixel`
      - Filter to specific tag if `--tag-filter` specified
      - For DicomSequence: call WriteSequenceStart, recurse into items up to --max-depth, call WriteSequenceEnd
      - For other elements: call WriteElement
   e. Call `formatter.WriteFileFooter(Console.Out)`
6. Return ExitCodes.Success

**Element traversal helper:**
Create a private `WriteDataset(DicomDataset dataset, IOutputFormatter formatter, DicomDictionary dict, int depth, int? maxDepth, bool noPrivate, bool noPixel, string? tagFilter, TextWriter output)` method that handles the recursive walking:
- If depth > maxDepth, write a "... (depth limit)" indicator and return
- For each element in dataset:
  - Apply filters
  - If DicomSequence: write sequence start, iterate items, write sequence end
  - Otherwise: call formatter.WriteElement

**Stdout/stderr discipline:**
- ALL structured output (the DICOM dump itself) goes to `Console.Out`
- ALL progress, errors, warnings go to `Console.Error`
- This allows `sharpdcm dump file.dcm --format json | jq .` to work correctly
