  <action>
Create `FindCommand.cs` as a static class with `public static Command Create()`.

**Arguments and Options:**
- `Option<string>("--level", () => "study", "Query level: patient, study, series, instance")` with alias `-l`
- `Option<string?>("--patient-name", "Patient name filter (supports wildcards: Smith*)")` with alias `-n`
- `Option<string?>("--patient-id", "Patient ID filter")`
- `Option<string?>("--accession", "Accession number filter")`
- `Option<string?>("--modality", "Modality filter (CT, MR, US, etc.)")` with alias `-m`
- `Option<string?>("--study-date", "Study date filter (YYYYMMDD or YYYYMMDD-YYYYMMDD range)")`
- `Option<string?>("--study-description", "Study description filter")`
- `Option<string[]>("--return-field", "Additional return fields by keyword or tag (e.g., PatientBirthDate or 00100030)")` with alias `-r`
- `Option<string>("--format", () => "text", "Output format: text, json, csv")` with alias `-f`
- `Option<int?>("--limit", "Maximum number of results to return")`
- Same PACS connection options as store: `--host`, `--port`, `--called-ae`, `--calling-ae`, `--connection`, `--profile`, `--tls`

**Handler logic (async):**

1. **Resolve PACS connection** using same pattern as StoreCommand (extract to a shared helper method in a `PacsConnectionResolver` static class if it makes sense, or duplicate the ~15 lines of resolution logic).

2. **Build DicomQuery:**
   ```csharp
   var query = level.ToLower() switch
   {
       "patient" => DicomQuery.ForPatients(),
       "study" => DicomQuery.ForStudies(),
       "series" => DicomQuery.ForSeries(),
       "instance" => DicomQuery.ForInstances(),
       _ => throw new ArgumentException($"Invalid level: {level}")
   };

   if (patientName != null) query = query.WithPatientName(patientName);
   if (patientId != null) query = query.WithPatientId(patientId);
   if (modality != null) query = query.WithModality(modality);
   if (studyDate != null) query = query.WithStudyDate(studyDate);
   // ... etc.

   // Add return fields
   foreach (var field in returnFields ?? Array.Empty<string>())
   {
       var tag = ResolveTag(field); // by keyword or hex string
       query = query.ReturnField(tag);
   }
   ```

3. **Default return fields per level** (added automatically if no --return-field specified):
   - Patient: PatientName, PatientID, PatientBirthDate, PatientSex
   - Study: PatientName, PatientID, StudyDate, StudyDescription, Modality, AccessionNumber, StudyInstanceUID
   - Series: SeriesNumber, SeriesDescription, Modality, NumberOfSeriesRelatedInstances, SeriesInstanceUID
   - Instance: SOPClassUID, SOPInstanceUID, InstanceNumber

4. **Execute query:**
   ```csharp
   await using var client = new DicomClient(clientOptions);
   var contexts = new[] { PresentationContext.CreateProposed(...) };
   await client.ConnectAsync(contexts, ct);

   var findScu = new CFindScu(client);
   var results = new List<DicomDataset>();
   int count = 0;

   await foreach (var result in findScu.QueryAsync(query, ct))
   {
       results.Add(result);
       count++;
       if (limit.HasValue && count >= limit.Value)
           break;
   }
   ```

5. **Format and output results:**

   **Text format:** Use Spectre.Console `Table` widget for columnar display:
   - Column headers from return field keywords
   - Row per result
   - Write to stdout via Console.Out

   **JSON format:** Array of objects, each object has keyword:value pairs:
   ```json
   [
     { "PatientName": "Smith^John", "StudyDate": "20240101", "Modality": "CT" },
     { "PatientName": "Doe^Jane", "StudyDate": "20240102", "Modality": "MR" }
   ]
   ```

   **CSV format:** Header row with keywords, data rows with values:
   ```
   PatientName,StudyDate,Modality
   Smith^John,20240101,CT
   Doe^Jane,20240102,MR
   ```
   Properly escape values containing commas or quotes (use double-quote escaping per RFC 4180).

6. **Summary** to stderr: "Found {count} results"

7. Return ExitCodes.Success (even if 0 results -- that's valid). ExitCodes.RuntimeError on connection/query errors.

**Tag resolution helper:**
`static DicomTag ResolveTag(string input)`:
- If input matches `[0-9A-Fa-f]{8}` or `[0-9A-Fa-f]{4},[0-9A-Fa-f]{4}`: parse as hex tag
- Otherwise: look up by keyword in DicomDictionary (case-insensitive match)
- Throw descriptive error if not found
