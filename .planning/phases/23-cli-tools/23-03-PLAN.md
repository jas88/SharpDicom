  <action>
Create `StoreCommand.cs` as a static class with a `public static Command Create()` method.

**Arguments and Options:**
- `Argument<FileSystemInfo[]>("files", "DICOM files or directories to send")` - required
- `Option<string?>("--host", "Remote PACS hostname")` with alias `-H`
- `Option<int>("--port", () => 104, "Remote PACS port")` with alias `-p`
- `Option<string?>("--called-ae", "Called AE title")` with alias `-c`
- `Option<string?>("--calling-ae", () => "SHARPDCM", "Calling AE title")`
- `Option<string?>("--connection", "Connection string (pacs://AET@host:port)")` with alias `-C`
- `Option<string?>("--profile", "Named PACS profile from config")`
- `Option<int>("--retry", () => 0, "Number of retries on failure")` with alias `-r`
- `Option<bool>("--tls", () => false, "Use TLS encryption")`
- `Option<bool>("--continue-on-error", () => false, "Continue sending remaining files after an error")`

**Handler logic (async):**

1. **Resolve PACS connection** (precedence: flags > connection string > profile > error):
   a. If `--host` provided, use flags (host, port, called-ae, calling-ae)
   b. Else if `--connection` provided, parse with ConnectionStringParser
   c. Else if `--profile` provided, load from ConfigLoader
   d. Else: print error "No PACS connection specified. Use --host, --connection, or --profile." and return ExitCodes.UsageError

2. **Enumerate files** using FileEnumerator.EnumerateFiles, collect to list (need count for progress)

3. **Validate** at least one file found. If empty: "No DICOM files found" to stderr, return ExitCodes.UsageError

4. **Create DicomClient:**
   ```csharp
   var clientOptions = new DicomClientOptions
   {
       Host = host,
       Port = port,
       CalledAE = calledAe,
       CallingAE = callingAe,
   };
   // If --tls, set TlsOptions on client
   ```

5. **Connect** with presentation contexts proposing common storage SOP classes. Read the SOP Class UID from the first file to propose the right context, or propose a broad set of storage SOP classes.

   Practical approach: For each file, read the file first (DicomFile.OpenAsync), extract the SOPClassUID and TransferSyntax, then create a presentation context for that SOP class. Batch files by SOP class if possible, but for simplicity: connect once with a broad set of abstract syntaxes, or reconnect per-SOP-class if association rejected.

   Simpler approach for v1: Open each file, get SOP Class UID, connect with that specific SOP class as presentation context, send, release. For batch: accumulate unique SOP classes from first pass, connect with all, send all.

   **Recommended approach:** Two-pass for efficiency:
   - First pass: enumerate all files, read just the SOP Class UID from each (open file, get tag 0008,0016)
   - Collect unique SOP classes
   - Connect once with presentation contexts for all unique SOP classes, with ExplicitVRLittleEndian and ImplicitVRLittleEndian transfer syntaxes
   - Second pass: send each file via CStoreScu.SendAsync

   If the two-pass approach is too complex (some files might be large), use the simpler single-pass approach with `await using var client`:
   - Read all file headers to get SOP Class UIDs (just metadata, not pixel data)
   - Connect with all needed presentation contexts
   - Send files one at a time with progress reporting

6. **Send loop** with progress:
   ```csharp
   var storeScu = new CStoreScu(client);
   int successCount = 0, failCount = 0;

   await progressReporter.RunWithProgress("Sending files", files.Count, async (advance, ct) =>
   {
       foreach (var filePath in files)
       {
           for (int attempt = 0; attempt <= retryCount; attempt++)
           {
               try
               {
                   var file = await DicomFile.OpenAsync(filePath, ct: ct);
                   var response = await storeScu.SendAsync(file, ct: ct);
                   if (response.IsSuccess)
                   {
                       successCount++;
                       break;
                   }
                   else if (attempt == retryCount)
                   {
                       Console.Error.WriteLine($"{filePath}: C-STORE failed: {response.Status}");
                       failCount++;
                   }
               }
               catch (Exception ex) when (attempt < retryCount)
               {
                   Console.Error.WriteLine($"{filePath}: Attempt {attempt + 1} failed: {ex.Message}");
               }
           }
           advance(1);
       }
   }, ct);
   ```

7. **Summary** to stderr: "Sent {successCount}/{total} files ({failCount} failed)"

8. **Cleanup:** Use `await using` on DicomClient to ensure association is properly released even on Ctrl+C. Register a CancellationToken callback that calls client.AbortAsync() if release times out.

9. **Return** ExitCodes.Success if all succeeded, ExitCodes.RuntimeError if any failed.

**Critical patterns:**
- `await using var client = new DicomClient(options);` for cleanup
- CancellationToken threaded through all async calls
- Progress to stderr only
- File opened per-send (not all loaded into memory at once)
