    All types in namespace `FellowOakDicom.Network.Client`:

    **IDicomClient.cs** - Interface matching fo-dicom's IDicomClient:
    - `Task AddRequestAsync(DicomRequest request)` -- buffers request
    - `Task SendAsync(CancellationToken ct = default)` -- executes all buffered requests
    - `Task NegotiateAsyncOps(int invoked = 0, int performed = 0)` -- async ops negotiation
    - Property: `IsBusy` (bool)

    **DicomClient.cs** - Implementation:
    - Internal fields: `_host`, `_port`, `_useTls`, `_callingAE`, `_calledAE`
    - Internal `List<DicomRequest> _requests` for buffering
    - `AddRequestAsync`: add request to buffer, return completed task
    - `NegotiateAsyncOps`: store values, return completed task (may be no-op initially)
    - `SendAsync` -- this is the critical bridge between fo-dicom's request-queue and SharpDicom's direct-call pattern. Explicit substeps:
      1. Create `SharpDicom.Network.DicomClient` with `DicomClientOptions` from stored config (`_host`, `_port`, `_callingAE`, `_calledAE`)
      2. Call `ConnectAsync(host, port)` on the SharpDicom client
      3. For each buffered `DicomCFindRequest`:
         a. **Extract query keys from request.Dataset**: Enumerate all DicomItems in the compat request.Dataset. For each item, get the underlying SharpDicom tag and value.
         b. **Create DicomQuery using QueryBuilder pattern**: Instantiate a `DicomQuery` (or use `QueryBuilder` if that's SharpDicom's API). Set `Level` by converting `request.Level` (compat `DicomQueryRetrieveLevel`) to SharpDicom's `QueryRetrieveLevel` via the internal conversion method.
         c. **Map each query key**: For each element in request.Dataset, add the corresponding tag+value to the DicomQuery. For example, if request.Dataset contains `DicomTag.StudyDate` with value "20200101-20201231", set that as a query key on the DicomQuery.
         d. **Execute via CFindScu**: Call `CFindScu.FindAsync(association, query)` or the equivalent SharpDicom C-FIND API, passing the constructed DicomQuery.
         e. **Invoke callbacks**: For each C-FIND result returned by SharpDicom, wrap it in a compat `DicomCFindResponse` (with Pending status and the result DicomDataset wrapped as compat), then invoke `request.OnResponseReceived(request, response)`.
         f. **Send final response**: After all results, invoke `OnResponseReceived` with a final `DicomCFindResponse` having Success status and null Dataset (signals end of results, matching fo-dicom's pattern).
      4. Dispose SharpDicom client
      5. Clear request buffer
    - Handle TLS: if `_useTls` is true, configure TlsOptions on SharpDicom client

    **DicomClientFactory.cs** - Static factory:
    - `Create(string host, int port, bool useTls, string callingAE, string calledAE)` returns `IDicomClient`
    - Simply constructs compat `DicomClient` with stored parameters
