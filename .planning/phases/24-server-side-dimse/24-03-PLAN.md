  <action>
  Create `src/SharpDicom/Storage/DicomMetadataIndex.cs`:

  A class that manages a SQLite database for DICOM instance metadata. Implements `IDisposable`.

  **Constructor**: Takes `string databasePath`. Creates/opens SQLiteConnection with `Data Source={databasePath}`. Calls `EnsureSchema()`.

  **EnsureSchema()**: Executes SQL to create tables and indexes if not exist:
  ```sql
  PRAGMA journal_mode = WAL;

  CREATE TABLE IF NOT EXISTS patients (
      patient_id TEXT PRIMARY KEY,
      patient_name TEXT,
      patient_birth_date TEXT,
      patient_sex TEXT
  );

  CREATE TABLE IF NOT EXISTS studies (
      study_instance_uid TEXT PRIMARY KEY,
      patient_id TEXT NOT NULL,
      study_date TEXT,
      study_time TEXT,
      study_description TEXT,
      accession_number TEXT,
      referring_physician TEXT,
      modalities_in_study TEXT
  );

  CREATE TABLE IF NOT EXISTS series (
      series_instance_uid TEXT PRIMARY KEY,
      study_instance_uid TEXT NOT NULL,
      modality TEXT,
      series_number TEXT,
      series_description TEXT,
      body_part_examined TEXT
  );

  CREATE TABLE IF NOT EXISTS instances (
      sop_instance_uid TEXT PRIMARY KEY,
      series_instance_uid TEXT NOT NULL,
      sop_class_uid TEXT NOT NULL,
      instance_number TEXT,
      file_path TEXT NOT NULL,
      file_size INTEGER,
      transfer_syntax_uid TEXT,
      indexed_at TEXT NOT NULL
  );
  ```
  Plus indexes per RESEARCH.md schema (idx_patients_name, idx_studies_date, idx_studies_accession, idx_studies_patient, idx_series_study, idx_series_modality, idx_instances_series, idx_instances_sop_class).

  NOTE: Do NOT add REFERENCES/foreign key constraints -- SQLite doesn't enforce them by default and they complicate upsert operations. Use INSERT OR REPLACE for idempotent indexing.

  **IndexInstance(DicomDataset dataset, string relativePath, long fileSize)**:
  - Extract metadata from dataset:
    - PatientID (0010,0020), PatientName (0010,0010), PatientBirthDate (0010,0030), PatientSex (0010,0040)
    - StudyInstanceUID (0020,000D), StudyDate (0008,0020), StudyTime (0008,0030), StudyDescription (0008,1030), AccessionNumber (0008,0050), ReferringPhysicianName (0008,0090)
    - SeriesInstanceUID (0020,000E), Modality (0008,0060), SeriesNumber (0020,0011), SeriesDescription (0008,103E), BodyPartExamined (0018,0015)
    - SOPInstanceUID (0008,0018), SOPClassUID (0008,0016), InstanceNumber (0020,0013), TransferSyntaxUID from FileMetaInfo
  - Use a transaction wrapping 4 INSERT OR REPLACE statements (one per table)
  - For ModalitiesInStudy: Update studies row to include the modality from this series (comma-separated, deduplicated)
  - Use parameterized queries ($param) -- never string interpolation

  **FindAsync(DicomDataset queryIdentifier, CancellationToken ct)** returns `IAsyncEnumerable<DicomDataset>`:
  - Parse QueryRetrieveLevel from the identifier
  - Build SQL query based on level:
    - PATIENT: SELECT from patients WHERE matching keys
    - STUDY: SELECT from patients JOIN studies WHERE matching keys
    - SERIES: JOIN through to series
    - IMAGE: JOIN through to instances
  - For each matching/return key in the identifier:
    - If value is non-empty: add WHERE clause using DicomQueryMatcher.DicomWildcardToSqlLike for wildcard values, exact match for UIDs, DicomDateRange.Parse for date ranges
    - If value is empty (zero-length): it's a return key, include in SELECT
  - Use `LIKE $pattern ESCAPE '\'` for wildcard columns
  - Use `COLLATE NOCASE` for PatientName comparisons (PN VR is case-insensitive per PS3.4 C.2.2.2.4)
  - Execute query with SqliteDataReader (synchronous -- SQLite is sync per RESEARCH.md)
  - Yield return DicomDataset for each row with the requested fields populated
  - Since this must return IAsyncEnumerable but SQLite is sync, use `Task.Run` to offload the blocking read to the thread pool, or simply yield synchronously (IAsyncEnumerable allows synchronous yields)

  **GetFilePath(string sopInstanceUid)** returns `string?`:
  - SELECT file_path FROM instances WHERE sop_instance_uid = $uid
  - Returns the relative file path or null

  **RemoveInstance(string sopInstanceUid)**:
  - DELETE from instances WHERE sop_instance_uid = $uid

  **GetInstanceCount()** returns `int`:
  - SELECT COUNT(*) FROM instances

  Thread safety: Use a SemaphoreSlim(1,1) for write operations. Read operations can proceed concurrently (WAL mode). Use separate SqliteConnection for reads vs writes (connection per operation for reads, persistent connection for writes).

  Actually, simpler approach per RESEARCH.md: Single long-lived connection with WAL mode. SQLite handles concurrent reads internally. Use SemaphoreSlim for write serialization. For reads in FindAsync, use the same connection but ensure writes are serialized.

  Use synchronous ADO.NET methods (Open, ExecuteNonQuery, ExecuteReader, ExecuteScalar) per RESEARCH.md Pitfall 4 -- SQLite async is actually sync.

  Create an integrated store+serve class implementing `IDisposable`:

  **Constructor**: Takes `FileSystemDicomStoreOptions options`. Creates the root directory if not exists. Creates `DicomMetadataIndex` with database path.

  **StoreAsync(CStoreRequestContext context, DicomDataset dataset, CancellationToken ct)**:
  Returns `ValueTask<DicomStatus>`:
  - Extract PatientID, StudyInstanceUID, SeriesInstanceUID, SOPInstanceUID from dataset
  - Build relative path: `{patientId}/{studyUid}/{seriesUid}/{sopUid}.dcm`
  - Sanitize path components (replace invalid chars with underscores)
  - Create directories as needed
  - Write DicomFile to full path using DicomFileWriter (or DicomFile.SaveAsync if available)
  - Call `_index.IndexInstance(dataset, relativePath, fileSize)`
  - Return DicomStatus.Success
  - On exception: return DicomStatus.ProcessingFailure

  **FindAsync(DicomDataset queryIdentifier, CancellationToken ct)**:
  Returns `IAsyncEnumerable<DicomDataset>`:
  - Delegate to `_index.FindAsync(queryIdentifier, ct)`

  **RetrieveAsync(DicomDataset matchedInstance, CancellationToken ct)**:
  Returns `ValueTask<DicomFile?>`:
  - Extract SOPInstanceUID from matchedInstance
  - Call `_index.GetFilePath(sopInstanceUid)` to get relative path
  - If null, return null
  - Build full path from root directory + relative path
  - Load and return DicomFile using `DicomFile.OpenAsync(fullPath)` (or appropriate method)
  - On error, return null

  **CreateServerOptions()** returns `DicomServerOptions`:
  Helper that creates a fully wired DicomServerOptions:
  ```csharp
  return new DicomServerOptions
  {
      AETitle = _storeOptions.AETitle,
      Port = _storeOptions.Port,
      OnCStoreRequest = (ctx, dataset, ct) => StoreAsync(ctx, dataset, ct),
      OnCFind = (query, ct) => FindAsync(query, ct),
      OnCMoveRetrieve = (match, ct) => RetrieveAsync(match, ct),
      OnCGetRetrieve = (match, ct) => RetrieveAsync(match, ct),
      // OnResolveMoveDestination left null -- caller must set if C-MOVE is needed
  };
  ```

  **GetInstanceCount()** returns `int`:
  - Delegate to `_index.GetInstanceCount()`

  **Dispose()**: Dispose the DicomMetadataIndex (which disposes the SqliteConnection).

  Path sanitization helper method:
  - Replace characters invalid in file paths (/, \, :, *, ?, <, >, |, ") with underscore
  - Truncate overly long path components
  - Handle empty PatientID (use "UNKNOWN" fallback)
