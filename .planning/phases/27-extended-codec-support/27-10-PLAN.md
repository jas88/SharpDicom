Create VideoDicomBuilderTests:

1. Test_Build_Endoscopic_H264: Build video DICOM with Endoscopic SOP class, H264 TS. Verify:
   - SOPClassUID = VideoEndoscopicImageStorage UID
   - TransferSyntax = H264HighProfile41
   - Modality = "ES"
   - Rows and Columns match specified dimensions
   - FrameTime calculated correctly from frame rate
   - SamplesPerPixel = 3
   - BitsAllocated = 8

2. Test_Build_AllSopClasses: Iterate all 7 VideoSopClass values, build each, verify correct SOP Class UID and Modality mapping.

3. Test_Build_AutoGeneratesUIDs: Build without specifying UIDs, verify SOPInstanceUID, SeriesInstanceUID, StudyInstanceUID are all generated with "2.25." prefix.

4. Test_Build_CustomUIDs: Build with explicit UIDs, verify they are used instead of auto-generated.

5. Test_Build_WithTemplate: Create a template dataset with patient info, build with template, verify patient attributes (PatientName, PatientID) are copied to output.

6. Test_Build_MissingRequiredFields: Try to build without SOP class, verify ArgumentException. Try without pixel data, verify exception. Try without dimensions, verify exception.

7. Test_Build_PixelDataAsSingleFragment: Build with sample video bytes, verify pixel data has exactly one fragment.

8. Test_Build_MPEG2_TransferSyntax: Build with MPEG2 codec, verify TransferSyntax = MPEG2MainML.

9. Test_Build_HEVC_TransferSyntax: Build with HEVC, verify TransferSyntax = HEVCMainProfile51.

3. Test_Review_Preset: Verify Review preset.

4. Test_Archive_Preset: Verify Archive preset.
