Create `native/BUILD-REQUIREMENTS.md` documenting the optional vendor library requirements for the native codec build.

The document should cover:

1. **Overview**: The native build system (build.zig) supports optional vendor libraries. When vendor sources are absent, stub implementations are compiled that return UNSUPPORTED at runtime. The managed C# codecs serve as fallback.

2. **Required tools**: Zig 0.13.0+ (cross-compilation toolchain).

3. **Optional vendor libraries** with a table:

| Feature | Build Flag | Vendor Path | Source |
|---------|-----------|-------------|--------|
| 8-bit JPEG | `have_libjpeg` | `vendor/libjpeg-turbo/src` | https://github.com/libjpeg-turbo/libjpeg-turbo |
| 12-bit JPEG | `have_libjpeg12` | `vendor/libjpeg-turbo/src` (same source, compiled with `-DWITH_12BIT=1` and symbol prefix flags) | https://github.com/libjpeg-turbo/libjpeg-turbo |
| JPEG 2000 | `have_openjpeg` | `vendor/openjpeg/src` | https://github.com/uclouvain/openjpeg |
| JPEG-LS | `have_charls` | `vendor/charls/src` | https://github.com/team-charls/charls |
| FFmpeg (decode) | `have_ffmpeg` | `vendor/ffmpeg/` | https://github.com/FFmpeg/FFmpeg |
| FFmpeg (encode) | `have_ffmpeg_enc` | `vendor/ffmpeg/` + `vendor/x264/` + `vendor/x265/` | https://github.com/FFmpeg/FFmpeg, https://code.videolan.org/videolan/x264, https://bitbucket.org/multicoreware/x265_git |

4. **Enabling 12-bit JPEG specifically**:
   - Clone libjpeg-turbo: `git clone https://github.com/libjpeg-turbo/libjpeg-turbo.git vendor/libjpeg-turbo/src`
   - In `build.zig`, set `have_libjpeg12 = true` (line 19)
   - The build system automatically compiles 12-bit sources with symbol prefix flags (`jpeg_*` becomes `jpeg12_jpeg_*`) so 8-bit and 12-bit coexist in the same shared library
   - The 12-bit build does NOT use TurboJPEG or SIMD (incompatible with WITH_12BIT); the 8-bit path retains full SIMD performance

5. **Fallback behavior**: When `have_libjpeg12 = false` (default), the build compiles a stub `jpeg12_wrapper.c` that returns error codes. At runtime, `NativeCodecs.HasFeature(NativeCodecFeature.Jpeg12Bit)` returns false, and the managed `JpegExtendedCodec` handles 12-bit JPEG decoding/encoding instead.

6. **CI notes**: The CI workflow builds without vendor sources by default. To test native 12-bit JPEG in CI, add a build matrix variant that fetches vendor sources before building.

Keep the document concise and focused. No marketing language.
