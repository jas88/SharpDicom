Helper method for PSNR calculation:
```csharp
static double CalculatePsnr(ReadOnlySpan<ushort> original, ReadOnlySpan<ushort> decoded, int maxValue)
{
    double mse = 0;
    for (int i = 0; i < original.Length; i++)
    {
        double diff = original[i] - decoded[i];
        mse += diff * diff;
    }
    mse /= original.Length;
    if (mse == 0) return double.PositiveInfinity;
    return 10.0 * Math.Log10(maxValue * maxValue / mse);
}
```
