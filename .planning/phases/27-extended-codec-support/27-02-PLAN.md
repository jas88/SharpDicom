  <action>
Create JpegExtendedDecoder: a pure C# decoder for 12-bit JPEG (Process 2,4).

Key differences from JpegBaselineDecoder (8-bit):
- Parse SOF1 marker (0xFFC1) instead of SOF0 (0xFFC0). SOF1 indicates Extended Sequential DCT.
- Sample precision field in SOF1 can be 8 or 12 (vs always 8 in SOF0).
- DCT coefficients use extended precision (12-bit samples need wider coefficient range).
- Output is ushort[] (16-bit) instead of byte[] -- each sample stored in a ushort even for 12-bit.
- Huffman decoding categories extend to 12 (vs 11 for 8-bit).
- Quantization tables use 16-bit entries (vs 8-bit in baseline).
- Dequantized coefficients need wider arithmetic (int instead of short).

Implementation approach:
1. Reuse existing JpegMarkers, BitReader, HuffmanTable infrastructure.
2. Extend DctTransform to work with int[] coefficients (or create a 12-bit variant).
3. Decoder reads SOF1, determines precision (8 or 12), decodes Huffman-coded DCT coefficients.
4. For 12-bit: output samples clamped to [0, 4095] range stored in ushort.
5. Also handle 8-bit data in SOF1 (valid per JPEG standard).

Create JpegExtendedEncoder: a pure C# encoder for 12-bit JPEG.
- Write SOF1 marker with precision=12.
- Extended Huffman tables (categories 0-12 for DC, 0-12 for AC).
- Quantization tables scaled for 12-bit range.
- Input is ushort[] (12-bit samples in 16-bit containers).
- Output is standard JPEG bitstream with SOF1.

The encoder and decoder should follow the same patterns as JpegBaselineEncoder/Decoder but parameterized for the wider sample precision. Where possible, share code by extracting common helpers.
