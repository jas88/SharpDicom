1. Create NativeJpeg8Codec:
   - This is essentially a renamed copy of the existing NativeJpegCodec that explicitly targets 8-bit JPEG Baseline.
   - TransferSyntax => TransferSyntax.JPEGBaseline
   - Name => "Native JPEG 8-bit (libjpeg-turbo)"
   - Capabilities: same as NativeJpegCodec (8-bit, grayscale+RGB, lossy)
   - Implementation: delegates to NativeMethods.jpeg_decode/jpeg_encode (the existing 8-bit P/Invoke)
   - Follow NativeJpegCodec pattern exactly.

2. Create NativeJpeg12Codec implementing IPixelDataCodec:
   - TransferSyntax => TransferSyntax.JPEGExtended
   - Name => "Native JPEG 12-bit (libjpeg-turbo)"
   - Capabilities: CanEncode=true, CanDecode=true, IsLossy=true, SupportsMultiFrame=true, SupportsParallelEncode=true, SupportedBitDepths=[8,12], SupportedSamplesPerPixel=[1,3]

   Decode method:
   - Extract fragment for frameIndex
   - Pin fragment and destination buffers
   - Call NativeMethods.jpeg12_decode(fragmentPtr, fragmentLen, destPtr, destLen, out width, out height, out components)
   - Check result < 0 for error, get error message via NativeCodecs.GetLastError()
   - Verify dimensions match info.Columns/info.Rows
   - 12-bit output is uint16_t values -- each pixel sample is 2 bytes in the output buffer
   - bytesWritten = width * height * components * 2 (16-bit per sample)
   - Return DecodeResult.Ok(bytesWritten)

   Encode method:
   - Accept ReadOnlySpan<byte> pixelData (which contains ushort values for 12-bit)
   - Pin input buffer
   - Call NativeMethods.jpeg12_encode(inputPtr, width, height, components, out outputPtr, out outputLen, quality)
   - Check result, copy native buffer to managed array, free native buffer
   - Create DicomFragmentSequence with single fragment
   - Use JpegEncodeOptions for quality (default 90)

   ValidateCompressedData: check SOI marker (0xFFD8), optionally verify SOF1 marker present.

Remove the existing NativeJpegCodec registration and replace it with NativeJpeg8Codec registration (same transfer syntax, same priority). This is a clean rename, not an addition. NativeJpegCodec.cs remains as-is for backward compatibility but is no longer registered by default -- NativeJpeg8Codec takes its place.
