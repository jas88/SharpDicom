Add the FFmpeg encoding build configuration to build.zig. This is structured as a preparatory build configuration -- the actual vendor source download happens in CI.

When have_ffmpeg_enc is true:

1. FFmpeg source compilation (following allyourcodebase/ffmpeg pattern):
   - Compile FFmpeg C source files directly via Zig (bypass configure/make)
   - Required components:
     - libavcodec: core encoding/decoding
     - libavutil: utility functions
     - libswscale: pixel format conversion
     - libswresample: audio resampling
     - libavformat: muxing/demuxing (for audio interleave and container output)
   - Minimal codec configuration (matching RESEARCH.md configure flags):
     - Encoders: mpeg2video, libx264, libx265, aac, pcm_s16le
     - Decoders: mpeg2video, h264, hevc, aac, pcm_s16le (already present from Phase 13)
     - Muxers: rawvideo, h264, hevc, mpegvideo, adts, wav
   - A config.h header must be generated with appropriate defines:
     - CONFIG_MPEG2VIDEO_ENCODER, CONFIG_LIBX264_ENCODER, CONFIG_LIBX265_ENCODER, etc.
     - Platform-specific defines (HAVE_ALIGNED_MALLOC, etc.)
   - Add vendor/ffmpeg/include to include paths

2. x264 source compilation:
   - Compile x264 C source files directly via Zig
   - Requires a generated x264_config.h with:
     - BIT_DEPTH=8 (or 10 for 10-bit)
     - X264_CHROMA_FORMAT=0 (all formats)
     - Platform-specific assembly defines
   - Add vendor/x264/include to include paths
   - Link x264 object files into sharpdicom_codecs

3. x265 source compilation:
   - Compile x265 C/C++ source files via Zig
   - Requires a generated x265_config.h
   - x265 is C++ -- Zig can compile C++ with addCSourceFile using .cpp extension
   - Add vendor/x265/include to include paths

4. Structure the build.zig additions clearly:
   ```zig
   // FFmpeg encoding support
   if (have_ffmpeg_enc) {
       // x264 (H.264 encoder)
       // ... compile x264 source files

       // x265 (HEVC encoder)
       // ... compile x265 source files

       // FFmpeg (libavcodec, libavformat, libswscale, libswresample)
       // ... compile FFmpeg source files

       // video_encoder.c with encoding enabled
       lib.addCSourceFile(.{
           .file = b.path("src/video_encoder.c"),
           .flags = common_flags ++ &[_][]const u8{"-DSHARPDICOM_WITH_FFMPEG_ENC"},
       });
   } else {
       // Stub mode
       lib.addCSourceFile(.{
           .file = b.path("src/video_encoder.c"),
           .flags = common_flags,
       });
   }
   ```

5. Add TODO comments for the exact source file lists for FFmpeg/x264/x265 (these will be populated when vendor sources are downloaded). The structure should be clear enough that adding the file lists is mechanical.
