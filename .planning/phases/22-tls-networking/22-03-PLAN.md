**Step 1: Change method signatures from NetworkStream to Stream**
All internal methods that currently take `NetworkStream stream` must be changed to `Stream stream`:
- `HandleAssociationAsync(TcpClient client, CancellationToken ct)` — no parameter change but internal stream variable type changes
- `RunDimseLoopAsync(NetworkStream stream, ...)` → `RunDimseLoopAsync(Stream stream, ...)`
- `HandlePDataAsync(NetworkStream stream, ...)` — this doesn't take stream directly but calls other methods
- `ReadAssociateRequestAsync(NetworkStream stream, ...)` → `ReadAssociateRequestAsync(Stream stream, ...)`
- `ReadPduAsync(NetworkStream stream, ...)` → `ReadPduAsync(Stream stream, ...)`
- `ReadExactlyAsync(NetworkStream stream, ...)` → `ReadExactlyAsync(Stream stream, ...)`
- `SendAssociateAcceptAsync(NetworkStream stream, ...)` → `SendAssociateAcceptAsync(Stream stream, ...)`
- `SendAssociateRejectAsync(NetworkStream stream, ...)` → `SendAssociateRejectAsync(Stream stream, ...)`
- `SendReleaseResponseAsync(NetworkStream stream, ...)` → `SendReleaseResponseAsync(Stream stream, ...)`
- `SendCEchoResponseAsync(NetworkStream stream, ...)` → `SendCEchoResponseAsync(Stream stream, ...)`
- `SendCStoreResponseAsync(NetworkStream stream, ...)` → `SendCStoreResponseAsync(Stream stream, ...)`
- `ReadDatasetAsync(NetworkStream stream, ...)` → `ReadDatasetAsync(Stream stream, ...)`
- `ReadAndDiscardDatasetAsync(NetworkStream stream, ...)` → `ReadAndDiscardDatasetAsync(Stream stream, ...)`
- `HandleCEchoAsync(NetworkStream stream, ...)` → `HandleCEchoAsync(Stream stream, ...)`
- `HandleCStoreAsync(NetworkStream stream, ...)` → `HandleCStoreAsync(Stream stream, ...)`

This is safe because all these methods only use `Stream` APIs (ReadAsync, WriteAsync) — none use NetworkStream-specific members.

**Step 2: Add SslStreamCertificateContext caching**

In `Start()`, if TLS is configured, pre-build the context:

if (_options.Tls != null)

**Step 3: Modify HandleAssociationAsync to perform TLS handshake**
After `var stream = client.GetStream();`, insert TLS handshake before ARTIM timer:

```csharp
Stream activeStream = stream;

if (_options.Tls != null)
{
    var sslStream = new SslStream(
        stream,
        leaveInnerStreamOpen: false,
        _options.Tls.ClientCertificateValidationCallback);

    var serverAuthOptions = new SslServerAuthenticationOptions
    {
        #if NET6_0_OR_GREATER
        ServerCertificateContext = _certificateContext,
        #endif
        ServerCertificate = _options.Tls.ServerCertificate,
        ClientCertificateRequired = _options.Tls.RequireClientCertificate,
        EnabledSslProtocols = _options.Tls.EnabledProtocols ?? SslProtocols.None,
        CertificateRevocationCheckMode = _options.Tls.RevocationMode,
    };

    try
    {
        using var handshakeCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        handshakeCts.CancelAfter(_options.Tls.HandshakeTimeout);

        #if NET6_0_OR_GREATER
        await sslStream.AuthenticateAsServerAsync(serverAuthOptions, handshakeCts.Token)
            .ConfigureAwait(false);
        #else
        await sslStream.AuthenticateAsServerAsync(
            _options.Tls.ServerCertificate!,
            clientCertificateRequired: _options.Tls.RequireClientCertificate,
            enabledSslProtocols: _options.Tls.EnabledProtocols ?? SslProtocols.None,
            checkCertificateRevocation: _options.Tls.RevocationMode != X509RevocationMode.NoCheck)
            .ConfigureAwait(false);
        #endif
    }
    catch (Exception ex) when (ex is AuthenticationException or OperationCanceledException)
    {
        sslStream.Dispose();
        return; // Connection failed TLS, close silently
    }

    // Validate DICOM TLS profile compliance
    if (_options.Tls.EnforceDicomTlsProfile)
    {
        if (!DicomTlsProfile.IsCompliantProtocol(sslStream.SslProtocol))
        {
            sslStream.Dispose();
            return;
        }

        #if NET6_0_OR_GREATER
        if (!DicomTlsProfile.IsCompliant(sslStream.NegotiatedCipherSuite.ToString()))
        {
            sslStream.Dispose();
            return;
        }
        #endif
    }

    activeStream = sslStream;
}
```

Then pass `activeStream` instead of `stream` to all subsequent calls:
- `ReadAssociateRequestAsync(activeStream, artimCts.Token)`
- `SendAssociateAcceptAsync(activeStream, ...)`
- `SendAssociateRejectAsync(activeStream, ...)`
- `RunDimseLoopAsync(activeStream, association, ct)`
