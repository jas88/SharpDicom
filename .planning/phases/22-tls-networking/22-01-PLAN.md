**TlsOptions.cs** — Client-side TLS configuration:
- `SslProtocols? EnabledProtocols` — defaults to null (SslProtocols.None = OS default)
- `RemoteCertificateValidationCallback? ServerCertificateValidationCallback` — custom server cert validation
- `X509CertificateCollection? ClientCertificates` — for mTLS client certs
- `X509Certificate2? ClientCertificate` — convenience single cert property (adds to collection)
- `X509ChainPolicy? CertificateChainPolicy` — for custom trust stores (CustomRootTrust mode)
- `List<string>? AcceptedThumbprints` — SHA256 thumbprint whitelist for self-signed
- `List<X509Certificate2>? CustomCAs` — custom CA certificates for closed networks
- `bool AllowProtocolDowngrade` — default false, reject if negotiated < requested
- `bool EnforceDicomTlsProfile` — default true, validate cipher suite after handshake
- `TimeSpan HandshakeTimeout` — default 30 seconds
- `X509RevocationMode RevocationMode` — default Online
- `void Validate()` method — validates configuration consistency
- Use `#if !NETSTANDARD2_0` for CipherSuitesPolicy (not available on ns2.0)

**TlsServerOptions.cs** — Server-side TLS configuration:
- `X509Certificate2? ServerCertificate` — server cert with private key
- `SslStreamCertificateContext? ServerCertificateContext` — for session resumption (net5.0+)
- `bool RequireClientCertificate` — default false
- `RemoteCertificateValidationCallback? ClientCertificateValidationCallback` — validate client certs
- `SslProtocols? EnabledProtocols` — defaults to null (OS default)
- `bool EnforceDicomTlsProfile` — default true
- `TimeSpan HandshakeTimeout` — default 30 seconds
- `X509RevocationMode RevocationMode` — default Online
- `void Validate()` method — validates server cert is present and has private key

**TlsConnectionInfo.cs** — Post-handshake connection state (readonly record struct on net6.0+, regular class on ns2.0):
- `SslProtocols Protocol`
- `string CipherSuiteName` (string instead of TlsCipherSuite enum for ns2.0 compat)

- `bool IsMutuallyAuthenticated`

All types in `SharpDicom.Network.Tls` namespace (exceptions stay in `SharpDicom.Network.Exceptions`).

**CertificateValidator.cs** — Reusable certificate validation with multiple strategies:
- Constructor takes `CertificateValidatorOptions` (thumbprints, custom CAs, allowSelfSigned flag)
- `bool Validate(object sender, X509Certificate? certificate, X509Chain? chain, SslPolicyErrors sslPolicyErrors)` — implements `RemoteCertificateValidationCallback` signature
- Validation pipeline:
  1. Reject if no certificate provided
  2. If pinned thumbprints configured: accept if match, reject if not (short-circuit)
  3. If system validation passed (SslPolicyErrors.None): accept
  4. If custom CAs configured: build chain with CustomRootTrust mode, accept if valid
  5. If self-signed allowed: check chain status is only UntrustedRoot and chain length == 1
  6. Reject otherwise
- `static CertificateValidator SystemOnly()` — factory for strict system store validation
- `static CertificateValidator AcceptThumbprints(params string[] thumbprints)` — factory for thumbprint whitelist
- `static CertificateValidator AcceptSelfSigned()` — factory for self-signed acceptance
- Thread-safe (no mutable state after construction)

**TlsOptionsTests.cs** — Unit tests for TLS configuration:
- `Validate_DefaultOptions_Succeeds`
- `Validate_MissingServerCert_Throws` (TlsServerOptions)
- `Validate_ServerCertWithoutPrivateKey_Throws`
- `EnabledProtocols_DefaultsToNull`
- `HandshakeTimeout_DefaultsTo30Seconds`

**CertificateValidatorTests.cs** — Unit tests for validation strategies:
- `SystemOnly_AcceptsValidCert` (SslPolicyErrors.None)

- `ThumbprintWhitelist_AcceptsMatchingThumbprint`

- `CustomCA_AcceptsCASignedCert`
- `CustomCA_RejectsUnrelatedCert`
- `NullCertificate_AlwaysRejects`

Use self-signed test certificates generated with `X509Certificate2.CreateFromPem()` (net6.0+) or `new X509Certificate2(byte[])` for testing.
For netstandard2.0 tests, use `RSA.Create()` + `CertificateRequest` to generate test certs programmatically if needed — or conditionally skip cert generation tests on ns2.0.
