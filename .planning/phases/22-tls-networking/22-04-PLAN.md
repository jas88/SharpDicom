**TlsCertificateHelper.cs** — Generate self-signed test certificates programmatically:
- `static X509Certificate2 CreateSelfSignedCertificate(string subjectName, TimeSpan validity)` — creates cert with private key using RSA 2048-bit, SHA256 signature
- `static (X509Certificate2 CA, X509Certificate2 Leaf) CreateCASignedCertificate(string caSubject, string leafSubject)` — creates CA cert and leaf cert signed by CA
- `static X509Certificate2 CreateExpiredCertificate(string subjectName)` — creates cert that expired yesterday
- `static X509Certificate2 CreateClientCertificate(string subjectName, X509Certificate2? signerCert = null)` — creates cert with client auth EKU
- Use `CertificateRequest` API (net6.0+). On netstandard2.0, use `#if NETSTANDARD2_0` to skip tests that require cert generation.
- Include `SubjectAlternativeName` extension with `localhost` and `127.0.0.1` for server certs.
- Private key export must work for SslStream (use `X509KeyStorageFlags.Exportable` or `CreateFromPem`).

**TlsIntegrationTests.cs** — Integration tests:

Test pattern: Each test starts a DicomServer with TLS on a random port, connects a DicomClient with matching TLS config, performs a DIMSE operation, then disposes both.

Use `[Category("Integration")]` attribute on all tests. Use NUnit `[TestFixture]`.

**Happy path tests:**
1. `CEcho_OverTls_Succeeds` — Self-signed cert with thumbprint whitelist, C-ECHO returns Success
2. `CEcho_OverTls_TlsConnectionInfoPopulated` — Verify TlsConnectionInfo has protocol, cipher, certificate info after handshake
3. `CStore_OverTls_RoundtripPreservesData` — C-STORE a simple dataset over TLS, verify received dataset matches
4. `MutualTls_BothCertsValid_Succeeds` — Server requires client cert, client provides valid cert, C-ECHO succeeds
5. `PlainTcp_StillWorks_WhenTlsNotConfigured` — Verify existing plain TCP path unchanged

**Certificate validation tests:**
6. `SelfSigned_AcceptedViaThumbprint` — Server uses self-signed cert, client whitelists thumbprint, connection succeeds
7. `SelfSigned_RejectedWithoutThumbprint` — Server uses self-signed cert, client has no whitelist, connection fails with TlsHandshakeException
8. `CustomCA_AcceptedWithCAInTrustStore` — CA-signed server cert, client trusts CA, connection succeeds (net6.0+ only due to CustomRootTrust)

**Error handling tests:**
9. `MutualTls_MissingClientCert_Fails` — Server requires client cert, client provides none, handshake fails
10. `TlsHandshakeTimeout_ThrowsTlsHandshakeException` — Server delays handshake response, client times out (may need careful test design — simplest approach: connect plain TCP client to TLS server, TLS server auth will fail/timeout)
11. `InvalidCert_Rejected` — Server uses expired cert, client rejects with CertificateValidationException or TlsHandshakeException

**Test infrastructure:**
- Helper method: `static int GetRandomPort()` — finds available port using `TcpListener(IPAddress.Loopback, 0)` then stops and returns port
- Helper method: `async Task WithTlsServerAsync(DicomServerOptions options, Func<int, Task> test)` — starts server, runs test, disposes server
- All tests should use `IPAddress.Loopback` for server binding and `localhost`/`127.0.0.1` for client host
- Use `Task.Delay` with `Task.WhenAny` for test timeouts (10 seconds max per test)
- Use `Assert.ThrowsAsync<TlsHandshakeException>` or `Assert.CatchAsync<TlsHandshakeException>` for error tests

**Conditional compilation:** Guard net6.0+-only tests with:
```csharp
#if NET6_0_OR_GREATER
[Test]
public async Task CustomCA_AcceptedWithCAInTrustStore() { ... }
#endif
```
This is necessary because CertificateRequest, X509ChainTrustMode.CustomRootTrust, and some cert generation APIs are only available on net6.0+.

**Important notes:**
- Self-signed certs for `localhost` need SAN extension (Subject Alternative Name) with DNS:localhost and IP:127.0.0.1
- Server cert MUST have private key for SslStream to work
- Client cert for mTLS MUST have private key
- Use `X509Certificate2.GetCertHashString(HashAlgorithmName.SHA256)` for thumbprint on net6.0+, `X509Certificate2.Thumbprint` (SHA1) on ns2.0
