  <action>
    Implement `BsonDicomReader` as a public static class in `SharpDicom.Serialization.Bson` namespace with:

    **Public API:**
    - `static DicomDataset Deserialize(byte[] bson, BsonSerializationOptions? options = null)` — main entry point
    - `static DicomDataset Deserialize(ReadOnlyMemory<byte> bson, BsonSerializationOptions? options = null)` — memory-based overload

    **Internal implementation:**

    The reader walks the raw BSON bytes sequentially. BSON format:
    - 4 bytes: document size (int32 LE)
    - Repeated: [type_byte][cstring_key][value]
    - 1 byte: 0x00 terminator

    **Parsing approach:**
    Use an `int offset` tracking current position in `ReadOnlySpan<byte>` (or `byte[]` for netstandard2.0).

    Helper methods:
    - `ReadInt32(data, ref offset)` — read 4 bytes LE, advance offset
    - `ReadInt64(data, ref offset)` — read 8 bytes LE, advance offset
    - `ReadDouble(data, ref offset)` — read 8 bytes as double LE, advance offset
    - `ReadCString(data, ref offset)` — read until null, return string, advance offset past null
    - `ReadBsonString(data, ref offset)` — read 4-byte length, then UTF-8 string, advance offset

    **Tag key parsing** — `ParseTagKey(string key)`:
    - Accept 8-char hex ("00100010"): parse group (first 4 hex) and element (last 4 hex)
    - Accept dotted ("0010.0010"): split on dot, parse each half
    - Accept keyword ("PatientName"): look up in DicomDictionary.Default
    - Return DicomTag

    **Element reconstruction from BSON sub-document:**

    Each DICOM element is stored as: `"tagkey": {"Value": [...], "Raw": "...", "vr": "PN"}`

    Parse the sub-document:
    1. Read the "vr" field if present to determine VR
    2. If no "vr" field, look up VR from DicomDictionary using the parsed tag
    3. Read "Raw" field if present (original DICOM string for dual-storage VRs)
    4. Read "Value" array

    **VR-based reconstruction:**

    - **String VRs with "Raw" field (IS, DS, DA, TM, DT):** Prefer "Raw" string for reconstruction. Encode "Raw" as UTF-8 bytes and create DicomStringElement. This preserves exact original DICOM values.
    - **PN:** Reconstruct from "Value" array (original DICOM string). The parsed Alphabetic/Ideographic/Phonetic sub-documents are informational only (queryability); the round-trip fidelity comes from the "Value" string.
    - **Other string VRs:** Read "Value" array of strings. If multiple values, join with backslash. Encode as UTF-8 bytes and create DicomStringElement.
    - **Numeric VRs (SS, US, SL, UL, FL, FD, SV, UV):** Read "Value" array of numbers. Write binary representation using BinaryPrimitives for each value. Create DicomNumericElement.
    - **AT:** Read "Value" array of hex strings. Parse each to DicomTag, write binary. Create DicomNumericElement with VR=AT.
    - **SQ:** Read "Value" BSON Array. Each element is a BSON Document — recursively deserialize to DicomDataset. Create DicomSequence.
    - **Binary VRs (OB, OW, OD, OF, OL, OV, UN):** Read "Value" as BSON Binary. Create DicomBinaryElement. If value is an external reference (has "$ref" key), create empty DicomBinaryElement (external data not loaded during deserialization).

    **Private tag handling:**
    - Check for "_private" key at top level
    - For each creator sub-document under "_private", iterate its elements
    - Register creator in dataset's PrivateCreatorDictionary
    - Private tags use Hex8 format — parse normally via ParseTagKey
    - Handle "_unknown" creator group (register elements without creator)

    **Error handling:**
    - Unknown BSON type byte: skip element (read past based on type rules)
    - Invalid tag key string: skip element, continue parsing
    - Malformed sub-document: skip element, continue parsing
    - Missing required fields: create empty element

    **netstandard2.0 compatibility:**
    - Use .ToArray() on ReadOnlyMemory to get byte[] for span-limited APIs
    - Use BinaryPrimitives for all numeric reads
    - String encoding via Encoding.UTF8.GetString(byte[], int, int)

    ```csharp
    namespace SharpDicom.Serialization.Bson;

    public static class DicomDatasetBsonExtensions
    {
        /// <summary>
        /// Serialize this dataset to BSON bytes.
        /// </summary>
        public static byte[] ToBson(this DicomDataset dataset,
            BsonSerializationOptions? options = null)
            => BsonDicomWriter.Serialize(dataset, options);

        /// <summary>
        /// Serialize this dataset to a BSON byte writer.
        /// </summary>
        public static void ToBson(this DicomDataset dataset,
            IBufferWriter<byte> writer,
            BsonSerializationOptions? options = null)
            => BsonDicomWriter.Serialize(dataset, writer, options);

        /// <summary>
        /// Deserialize a BSON document to a DicomDataset.
        /// </summary>
        public static DicomDataset FromBson(byte[] bson,
            BsonSerializationOptions? options = null)
            => BsonDicomReader.Deserialize(bson, options);

        /// <summary>
        /// Deserialize a BSON document to a DicomDataset.
        /// </summary>
        public static DicomDataset FromBson(ReadOnlyMemory<byte> bson,
            BsonSerializationOptions? options = null)
            => BsonDicomReader.Deserialize(bson, options);
    }
    ```

    Note: `FromBson` is a static method (not an extension method since there's no instance to extend). It's placed in the extensions class for discoverability alongside `ToBson`.
