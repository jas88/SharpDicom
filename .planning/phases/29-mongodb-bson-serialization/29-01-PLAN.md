  <action>
    Create the `src/SharpDicom/Serialization/Bson/` directory and implement these types:

    **BsonType.cs** — Internal static class with BSON type code constants per bsonspec.org:
    - Double = 0x01, String = 0x02, Document = 0x03, Array = 0x04, Binary = 0x05
    - Boolean = 0x08, DateTime = 0x09, Null = 0x0A, Int32 = 0x10, Int64 = 0x12

    **BsonTagKeyFormat.cs** — Public enum: Hex8 ("00100010"), Dotted ("0010.0010"), Keyword ("PatientName").

    **BsonOutputMode.cs** — Public enum: MongoNative (default, optimized for queries), DicomJson (PS3.18 Annex F, handled in Plan 03).

    **BinaryDataReference.cs** — Public sealed class representing an external binary reference:
    - `string ReferenceType` (e.g., "gridfs", "file")
    - `string? Id` (e.g., ObjectId string)
    - `string? Path` (e.g., file path)
    - Factory methods: `ForGridFs(string objectId)`, `ForFile(string path)`

    **FlattenProfile.cs** — Public sealed class for sequence flattening configuration:
    - `string Name` (e.g., "radiology", "pathology")
    - `HashSet<DicomTag> FlattenTags` — sequences to flatten
    - `static FlattenProfile Radiology` — predefined profile flattening Referenced Study Sequence (0008,1110), Referenced Series Sequence (0008,1115), Request Attributes Sequence (0040,0275), Procedure Code Sequence (0008,1032)
    - `FlattenProfile WithTag(DicomTag tag)` for custom additions

    **BsonSerializationOptions.cs** — Public sealed class with:
    - `BsonTagKeyFormat TagKeyFormat` (default Hex8)
    - `BsonOutputMode OutputMode` (default MongoNative)
    - `bool AlwaysIncludeVR` (default false — only ambiguous/private/retired)
    - `int BinaryInlineThreshold` (default 16384 = 16KB)
    - `Func<DicomTag, ReadOnlyMemory<byte>, BinaryDataReference>? ExternalBinaryHandler` — callback when binary exceeds threshold
    - `bool StripPrivateTags` (default false)
    - `int MaxSequenceDepth` (default 16)
    - `FlattenProfile? FlattenProfile` (default null — no flattening)
    - `static BsonSerializationOptions Default { get; }` — singleton with defaults

    **BsonDocumentBuffer.cs** — Internal sealed class wrapping a `byte[]` with a write position:
    - Constructor takes initial capacity (default 256)
    - `int Position` — current write position
    - `int Capacity` — current buffer capacity
    - `void EnsureCapacity(int additionalBytes)` — grow buffer if needed (double or exact, whichever is larger), using ArrayPool if >= 1024
    - `void WriteInt32(int value)` — write int32 little-endian at current position, advance 4
    - `void WriteInt64(long value)` — write int64 little-endian at current position, advance 8
    - `void WriteDouble(double value)` — write double little-endian (via BitConverter.DoubleToInt64Bits + WriteInt64LittleEndian), advance 8
    - `void WriteByte(byte value)` — write single byte, advance 1
    - `void WriteBytes(ReadOnlySpan<byte> data)` — copy bytes, advance
    - `void WriteCString(string value)` — write UTF-8 bytes + null terminator (no length prefix)
    - `void WriteBsonString(string value)` — write int32 length (including null) + UTF-8 bytes + null terminator
    - `void PatchInt32At(int offset, int value)` — write int32 at specific offset (for deferred document size)
    - `int BeginDocument()` — write placeholder 4 bytes, return position of size field
    - `void EndDocument(int sizeOffset)` — write 0x00 terminator, patch size at sizeOffset with (Position - sizeOffset)
    - `ReadOnlySpan<byte> WrittenSpan` — slice of buffer [0..Position]
    - `byte[] ToArray()` — copy WrittenSpan to new array
    - `void CopyTo(IBufferWriter<byte> target)` — write WrittenSpan to target
    - `void Reset()` — set Position = 0 without deallocating
    - Implements IDisposable to return ArrayPool buffers

    Use BinaryPrimitives for all little-endian writes. Use System.Text.Encoding.UTF8 for string encoding. Include #if NETSTANDARD2_0 guards where needed (e.g., Encoding.UTF8.GetBytes with Span overload not available on netstandard2.0 — use GetBytes(string) + copy instead).

<task type="auto">
  <name>Task 2: BsonDicomWriter serialization engine</name>
  <files>
    src/SharpDicom/Serialization/Bson/BsonDicomWriter.cs

  <action>
    Implement `BsonDicomWriter` as a public static class in `SharpDicom.Serialization.Bson` namespace with:

    **Public API:**
    - `static byte[] Serialize(DicomDataset dataset, BsonSerializationOptions? options = null)` — main entry point, returns BSON document as byte[]
    - `static void Serialize(DicomDataset dataset, IBufferWriter<byte> writer, BsonSerializationOptions? options = null)` — write to any IBufferWriter target

    **Internal implementation using BsonDocumentBuffer:**

    1. **Tag key formatting** — `FormatTagKey(DicomTag tag, BsonTagKeyFormat format)`:
       - Hex8: `$"{tag.Group:X4}{tag.Element:X4}"`
       - Dotted: `$"{tag.Group:X4}.{tag.Element:X4}"`
       - Keyword: dictionary lookup, fall back to Hex8

    2. **Element dispatch** — Switch on element type:
       - `DicomStringElement` → `WriteStringElement`
       - `DicomNumericElement` → `WriteNumericElement`
       - `DicomBinaryElement` → `WriteBinaryElement`
       - `DicomSequence` → `WriteSequenceElement`
       - `DicomPixelDataElement` → `WriteBinaryElement` (treat as binary)
       - `DicomFragmentSequence` → `WriteBinaryElement` (treat as binary)

    3. **WriteStringElement** — per VR:
       - IS: Dual storage. Parse each value to Int32 (fall back Int64 on overflow). Write sub-document: {"Value": [parsed...], "Raw": "original\\value"}. Value is BSON Array of Int32/Int64.
       - DS: Dual storage. Parse each value to Double. Write sub-document: {"Value": [parsed...], "Raw": "original\\value"}.
       - DA: Dual storage. Parse "YYYYMMDD" to UTC midnight DateTime (ms since epoch). Write {"Value": [datetime...], "Raw": "original"}.
       - TM: Dual storage. Parse "HHMMSS.FFFFFF" to Int64 milliseconds from midnight. Write {"Value": [ms...], "Raw": "original"}. Use BSON Int64 type (not DateTime).
       - DT: Dual storage. Parse full DICOM datetime to UTC DateTime. Write {"Value": [datetime...], "Raw": "original"}.
       - PN: Write {"Value": ["original"], "Alphabetic": {"FamilyName": "...", "GivenName": "...", "MiddleName": "...", "NamePrefix": "...", "NameSuffix": "..."}, "Ideographic": {...}, "Phonetic": {...}}. Split on `=` for component groups, then `^` for components. Include only non-empty component groups.
       - All other string VRs (AE, AS, CS, LO, SH, UC, UR, UT, LT, ST, UI, AT): Write {"Value": ["string_value"]}. For VM>1 (backslash-delimited), split and write array.

    4. **WriteNumericElement** — per VR:
       - SS → BSON Int32 array
       - US → BSON Int32 array
       - SL → BSON Int32 array
       - UL → BSON Int64 array (to avoid sign issues)
       - FL → BSON Double array
       - FD → BSON Double array
       - SV → BSON Int64 array
       - UV → BSON Int64 array (values > Int64.MaxValue fall back to string with Raw field)
       - AT → BSON String array (formatted as 8-char hex)
       All wrapped in {"Value": [...]}

    5. **WriteBinaryElement** — Check length vs BinaryInlineThreshold:
       - Below threshold: Write {"Value": BsonBinaryData(raw bytes, subtype Generic)}
       - Above threshold: If ExternalBinaryHandler provided, call it and write the reference: {"$ref": "type", "id": "...", "path": "..."}
       - If above threshold and no handler: Write {"Value": BsonBinaryData(raw bytes)} (inline anyway, with a size note)
       - Binary subtype: 0x00 (Generic)

    6. **WriteSequenceElement** — Write BSON Array of Documents:
       - Check depth against MaxSequenceDepth. If exceeded, serialize entire sequence as binary blob.
       - For each item (DicomDataset), recursively serialize as a BSON document within the array.
       - If FlattenProfile includes this sequence's tag AND depth==1: additionally write flattened dot-notation fields at the top level. E.g., "0008111000080018" for ReferencedSOPInstanceUID within Referenced Study Sequence.

    7. **Private tag grouping** — Separate private tags from standard tags:
       - If StripPrivateTags, skip all private elements.
       - Otherwise, collect private tags grouped by creator name (from `dataset.PrivateCreators.GetCreator(tag)`).
       - Write `_private` sub-document keyed by creator name. Each creator's sub-document contains their private elements.
       - Unknown-creator private tags go under `_private._unknown`.
       - Private tag elements use Hex8 key format regardless of TagKeyFormat option.

    8. **VR metadata** — Include "vr" field in element sub-document when:
       - AlwaysIncludeVR is true, OR
       - Tag is private, OR
       - DicomVRInfo for the tag indicates ambiguous VR (multi-VR tags like US/SS), OR
       - Tag is retired in the dictionary

    **Error handling:**
    - Invalid date/time strings: write null in Value, preserve in Raw
    - Empty elements: write {"Value": []} (empty array)
    - Null/missing values: write with BSON Null type

    **netstandard2.0 compatibility:**
    - Use BitConverter.DoubleToInt64Bits + BinaryPrimitives.WriteInt64LittleEndian for double writing
    - Use Encoding.UTF8.GetBytes(string) for string-to-bytes (not Span overload)
    - Use .ToArray() on ReadOnlyMemory where Span is not available
  </action>
