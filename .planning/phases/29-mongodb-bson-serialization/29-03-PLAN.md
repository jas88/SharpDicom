  <name>Task 1: DicomJsonWriter — PS3.18 Annex F serialization</name>
  <files>
    src/SharpDicom/Serialization/Bson/DicomJsonWriter.cs
  </files>
  <action>
    Implement `DicomJsonWriter` as a public static class using `System.Text.Json.Utf8JsonWriter`.

    **Public API:**
    - `static byte[] Serialize(DicomDataset dataset, BsonSerializationOptions? options = null)` — returns UTF-8 JSON bytes
    - `static void Serialize(DicomDataset dataset, Stream stream, BsonSerializationOptions? options = null)` — write to stream
    - `static string SerializeToString(DicomDataset dataset, BsonSerializationOptions? options = null)` — returns JSON string

    **PS3.18 Annex F format:**

    The DICOM-JSON model is a JSON object where each key is an 8-character uppercase hex tag:
    ```json
    {
      "00100010": { "vr": "PN", "Value": [{"Alphabetic": "Doe^John"}] },
      "00100020": { "vr": "LO", "Value": ["PAT001"] },
      "00080020": { "vr": "DA", "Value": ["20240115"] },
      "7FE00010": { "vr": "OW", "BulkDataURI": "http://..." }
    }
    ```

    **Key rules per PS3.18 F.2:**
    1. Keys are ALWAYS 8-char uppercase hex (GGGGEEEE)
    2. "vr" field ALWAYS present for every element
    3. Value field names: "Value", "BulkDataURI", or "InlineBinary"
    4. "Value" is always a JSON array (even for VM=1)
    5. Empty elements omit the "Value" field entirely (just {"vr": "XX"})

    **VR-specific serialization per PS3.18 F.2.3:**

    - **String VRs (AE, AS, CS, DA, DS, DT, IS, LO, LT, SH, ST, TM, UC, UI, UR, UT):** "Value" array of strings. For VM>1, split on backslash into array elements.
    - **PN:** "Value" array of objects, each with optional "Alphabetic", "Ideographic", "Phonetic" string fields. Split PN value on `=` for component groups.
    - **Numeric VRs (SS, US, SL, UL, FL, FD, SV, UV):** "Value" array of JSON numbers. SS/US/SL as integers, UL as number (may be >2^31), FL/FD as JSON doubles, SV/UV as numbers (UV > Int64.Max as string).
    - **IS:** "Value" array of integers (JSON number).
    - **DS:** "Value" array of JSON numbers (double).
    - **AT:** "Value" array of strings (8-char hex formatted).
    - **SQ:** "Value" array of JSON objects (recursive DICOM-JSON for each item).
    - **Binary VRs (OB, OW, OD, OF, OL, OV, UN):**
      - If ExternalBinaryHandler is set and length > threshold: write "BulkDataURI" with handler-provided URI
      - Otherwise: write "InlineBinary" with base64-encoded value

    **Private tags:** Include in the same flat structure (no _private grouping in DICOM-JSON mode). Keys are still 8-char hex.

    **Implementation:**
    - Use `Utf8JsonWriter` with `JavaScriptEncoder.UnsafeRelaxedJsonEscaping` for clean output
    - Write to `ArrayBufferWriter<byte>` for byte[] return, or directly to stream
    - JsonWriterOptions: Indented = false by default (add parameter for pretty-print)

    **netstandard2.0:** System.Text.Json is already a dependency of SharpDicom.

<task type="auto">
  <name>Task 2: DicomJsonReader — PS3.18 Annex F deserialization</name>
  <files>
    src/SharpDicom/Serialization/Bson/DicomJsonReader.cs
  </files>
  <action>
    Implement `DicomJsonReader` as a public static class using `System.Text.Json.JsonDocument`.

    **Public API:**
    - `static DicomDataset Deserialize(byte[] json, BsonSerializationOptions? options = null)`
    - `static DicomDataset Deserialize(ReadOnlyMemory<byte> json, BsonSerializationOptions? options = null)`
    - `static DicomDataset Deserialize(string json, BsonSerializationOptions? options = null)`
    - `static DicomDataset Deserialize(Stream stream, BsonSerializationOptions? options = null)`

    **Parsing approach:**
    - Parse JSON with `JsonDocument.Parse()`
    - Iterate root object properties — each key is a tag in 8-char hex
    - For each property, read the sub-object containing "vr" and "Value"/"InlineBinary"/"BulkDataURI"

    **Tag parsing:** Parse 8-char hex key to group (first 4) and element (last 4) -> DicomTag.

    **VR determination:** Read "vr" string field. Map to DicomVR using the existing `DicomVR.Parse()` or a static lookup.

    **Value reconstruction per VR:**

    - **String VRs:** Read "Value" array of JsonValueKind.String. Join with backslash for VM>1. Encode UTF-8 -> DicomStringElement.
    - **PN:** Read "Value" array of objects. Each object has "Alphabetic"/"Ideographic"/"Phonetic" string fields. Reconstruct DICOM PN format: `Alphabetic=Ideographic=Phonetic`, trim trailing `=`. The value of each component group is the raw DICOM string (e.g., "Doe^John").
    - **IS:** Read "Value" array as integers, format to string, join with backslash -> DicomStringElement (IS is a string VR in DICOM).
    - **DS:** Read "Value" array as numbers, format to string, join with backslash -> DicomStringElement.
    - **DA, TM, DT:** Read "Value" array as strings (DICOM format preserved in JSON) -> DicomStringElement.
    - **Numeric VRs:** Read "Value" array of numbers. Write binary representation:
      - SS: WriteInt16LE for each
      - US: WriteUInt16LE for each
      - SL: WriteInt32LE for each
      - UL: WriteUInt32LE for each
      - FL: WriteSingleLE for each (via Int32Bits)
      - FD: WriteDoubleLE for each (via Int64Bits)
      - SV: WriteInt64LE for each
      - UV: WriteUInt64LE for each (handle > Int64.Max via string fallback)
    - **AT:** Read "Value" array of hex strings. Parse to tag uint values, write binary -> DicomNumericElement.
    - **SQ:** Read "Value" array of objects. Recursively deserialize each -> DicomSequence.
    - **InlineBinary:** Base64-decode the string value -> DicomBinaryElement.
    - **BulkDataURI:** Store the URI string. Create empty DicomBinaryElement (data not loaded) — or optionally a reference element if a BulkDataURI handler is provided in options.

    **Empty elements:** If no "Value", "InlineBinary", or "BulkDataURI" field, create element with empty RawValue.

    **Error handling:**
    - Invalid JSON: throw JsonException (let System.Text.Json handle it)
    - Unknown VR string: try DicomDictionary lookup, fall back to UN
    - Invalid tag key: skip element
    - Type mismatch in Value array: best-effort conversion
  </action>
