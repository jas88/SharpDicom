**NServiceScu.cs:** Create a generic N-Service SCU class following the CFindScu/CStoreScu pattern:

```csharp
public sealed class NServiceScu
{
    private readonly DicomClient _client;
    private int _messageIdCounter;

    public NServiceScu(DicomClient client)
    {
        _client = client ?? throw new ArgumentNullException(nameof(client));
    }

    private ushort NextMessageId() => (ushort)Interlocked.Increment(ref _messageIdCounter);

    public async ValueTask<NServiceResponse> NCreateAsync(DicomUID sopClassUid, DicomDataset? attributeList, DicomUID? sopInstanceUid = null, CancellationToken ct = default) { ... }
    public async ValueTask<NServiceResponse> NSetAsync(DicomUID sopClassUid, DicomUID sopInstanceUid, DicomDataset modificationList, CancellationToken ct = default) { ... }
    public async ValueTask<NServiceResponse> NGetAsync(DicomUID sopClassUid, DicomUID sopInstanceUid, DicomTag[]? attributeIdentifierList = null, CancellationToken ct = default) { ... }
    public async ValueTask<NServiceResponse> NDeleteAsync(DicomUID sopClassUid, DicomUID sopInstanceUid, CancellationToken ct = default) { ... }
    public async ValueTask<NServiceResponse> NActionAsync(DicomUID sopClassUid, DicomUID sopInstanceUid, ushort actionTypeId, DicomDataset? actionInformation = null, CancellationToken ct = default) { ... }
    public async ValueTask<NServiceResponse> NEventReportAsync(DicomUID sopClassUid, DicomUID sopInstanceUid, ushort eventTypeId, DicomDataset? eventInformation = null, CancellationToken ct = default) { ... }
```

Each method:
1. Gets the accepted presentation context for the SOP Class UID from `_client.GetAcceptedContext(sopClassUid)`
2. Creates the appropriate DicomCommand using the factory methods from Plan 01
3. Sends the command (+optional dataset) via the client's internal DIMSE send mechanism (use `_client.SendDimseRequestAsync` or equivalent internal method)
4. Receives the response command (+optional dataset)
5. Returns an NServiceResponse

The SCU should use `_client`'s internal methods for sending commands. Look at how CStoreScu and CFindScu send their commands -- they use internal methods like `_client.SendDimseAsync` or write P-DATA PDVs directly. Follow that exact pattern.

```csharp
case CommandField.NCreateRequest:

    break;
case CommandField.NGetRequest:

    break;
case CommandField.NDeleteRequest:
    await HandleNDeleteAsync(stream, association, command, ct);
    break;
case CommandField.NActionRequest:

    break;
case CommandField.NEventReportRequest:
    await HandleNEventReportAsync(stream, association, command, dataset, ct);

```

Each HandleNXxxAsync method:
1. Extracts the SOP Class/Instance UIDs from the command (using Affected or Requested as appropriate)
2. Creates the appropriate request context
3. Checks if the corresponding handler is registered in options (e.g., `_options.NCreateHandler`)
4. If handler is null, sends a response with status 0x0110 (Processing Failure) or 0xA900 (NoSuchSOPClass)
5. If handler exists, calls handler.OnNXxxAsync() and sends the response
6. Response sending follows the existing pattern for C-STORE responses: build DicomCommand, serialize, write P-DATA

IMPORTANT: Follow the exact error handling and response sending patterns used by the existing C-STORE and C-FIND SCP handlers. Pay attention to how the dataset is consumed from the stream before sending a response.
