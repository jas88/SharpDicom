Extend DicomCommand with 12 factory methods and 4 new properties, following the exact pattern of existing C-Service factories.

**N-Service convenience properties (add after existing IsCCancelRequest):**
- `IsNEventReportRequest` / `IsNEventReportResponse`
- `IsNGetRequest` / `IsNGetResponse`
- `IsNSetRequest` / `IsNSetResponse`
- `IsNActionRequest` / `IsNActionResponse`
- `IsNCreateRequest` / `IsNCreateResponse`
- `IsNDeleteRequest` / `IsNDeleteResponse`

**N-Service command properties (add after AffectedSOPInstanceUID property):**
- `RequestedSOPInstanceUID` -- reads tag (0000,1001), returns DicomUID, same pattern as AffectedSOPInstanceUID but from RequestedSOPInstanceUID tag
- `EventTypeID` -- reads tag (0000,1002) via GetUInt16, returns ushort
- `ActionTypeID` -- reads tag (0000,1008) via GetUInt16, returns ushort

Note: `RequestedSOPClassUID` property already exists at line 69.

**Factory methods (add in Factory Methods region, after CreateCCancelRequest):**

CRITICAL: N-CREATE and N-EVENT-REPORT use **Affected** SOP UIDs. N-SET, N-GET, N-DELETE, N-ACTION use **Requested** SOP UIDs.

1. `CreateNEventReportRequest(ushort messageId, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, ushort eventTypeId)` -- uses AffectedSOPClassUID, AffectedSOPInstanceUID, EventTypeID (0000,1002), DataSetPresent
2. `CreateNEventReportResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, ushort eventTypeId, DicomStatus status, bool hasDataset = false)` -- same UIDs as request
3. `CreateNGetRequest(ushort messageId, DicomUID requestedSopClassUid, DicomUID requestedSopInstanceUid)` -- uses RequestedSOPClassUID, RequestedSOPInstanceUID, NoDataSetPresent (attribute list goes in command dataset as AttributeIdentifierList tag)
4. `CreateNGetResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, DicomStatus status, bool hasDataset = false)` -- response uses Affected UIDs per PS3.7
5. `CreateNSetRequest(ushort messageId, DicomUID requestedSopClassUid, DicomUID requestedSopInstanceUid)` -- uses RequestedSOPClassUID, RequestedSOPInstanceUID, DataSetPresent
6. `CreateNSetResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, DicomStatus status, bool hasDataset = false)` -- response uses Affected UIDs
7. `CreateNActionRequest(ushort messageId, DicomUID requestedSopClassUid, DicomUID requestedSopInstanceUid, ushort actionTypeId)` -- uses RequestedSOPClassUID, RequestedSOPInstanceUID, ActionTypeID (0000,1008), DataSetPresent
8. `CreateNActionResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, ushort actionTypeId, DicomStatus status, bool hasDataset = false)` -- response uses Affected UIDs
9. `CreateNCreateRequest(ushort messageId, DicomUID affectedSopClassUid, DicomUID? affectedSopInstanceUid = null)` -- uses AffectedSOPClassUID, optionally AffectedSOPInstanceUID, DataSetPresent
10. `CreateNCreateResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, DicomStatus status, bool hasDataset = false)` -- both UIDs required in response
11. `CreateNDeleteRequest(ushort messageId, DicomUID requestedSopClassUid, DicomUID requestedSopInstanceUid)` -- uses RequestedSOPClassUID, RequestedSOPInstanceUID, NoDataSetPresent
12. `CreateNDeleteResponse(ushort messageIdBeingRespondedTo, DicomUID affectedSopClassUid, DicomUID affectedSopInstanceUid, DicomStatus status)` -- NoDataSetPresent

All methods follow the AddUidElement/AddUInt16Element helper pattern already in the class. Use the existing `Dimse.CommandField.NCreateRequest` etc. constants.
