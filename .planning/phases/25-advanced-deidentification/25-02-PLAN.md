2. `void tess_delete(TessBaseAPI* handle)` -- calls TessBaseAPIDelete()

**TesseractHandle.cs:**
Create SafeHandle subclass for TessBaseAPI lifecycle:
```csharp
internal sealed class TesseractHandle : SafeHandleZeroOrMinusOneIsInvalid
{
    private TesseractHandle() : base(true) { }

    public static TesseractHandle Create()
    {
        var handle = new TesseractHandle();
        handle.SetHandle(TesseractNativeMethods.tess_create());
        return handle;
    }

    protected override bool ReleaseHandle()
    {
        TesseractNativeMethods.tess_delete(handle);
        return true;
    }
}
```
