<objective>
Implement UidReferenceWalker for comprehensive referenced SOP Instance UID updates across all sequences, and integrate it into the DicomDeidentifier pipeline.

Purpose: De-identification requires all cross-referenced UIDs (RT Plan, Presentation State, Structured Report, Key Object Selection, etc.) to be consistently remapped. The existing UidRemapper.RemapDataset() only handles top-level tags marked with RemapUid action by PS3.15 profiles. UidReferenceWalker performs a generic VR=UI traversal at unlimited depth, catching ALL UID references including those in nested sequences.

Output: UidReferenceWalker class, UidRemapResult type, and pipeline integration in DicomDeidentifier.

  <action>
Create UidRemapResult as a simple result class:
- UidsRemapped (int) -- count of UIDs that were remapped
- SequenceItemsTraversed (int) -- count of sequence items visited
- RemappedTags (List of DicomTag) -- specific tags that were remapped (for diagnostics)

Create UidReferenceWalker as a sealed class:
- Constructor takes UidRemapper (required, not owned)
- Public method: UidRemapResult RemapAllReferences(DicomDataset dataset, string? context = null)
- Private method: void WalkDataset(DicomDataset dataset, string? context, UidRemapResult result)

WalkDataset algorithm:
1. Collect all tags from dataset into a list (avoid modifying during enumeration, same pattern as existing DicomDeidentifier.ProcessDataset)
2. For each element:
   a. If DicomSequence: recurse into each item, increment SequenceItemsTraversed
   b. If VR == DicomVR.UI and element is DicomStringElement:
      - Get string value via GetString(DicomEncoding.Default)
      - Skip if null/whitespace
      - Trim the UID
      - Skip if UidRemapper.IsStandardUid(trimmedUid) returns true (preserves Transfer Syntax UIDs, SOP Class UIDs, etc.)
      - Call UidRemapper.Remap(trimmedUid, context) to get new UID
      - If newUid != trimmedUid, create new DicomStringElement with remapped bytes and add to dataset
      - Increment UidsRemapped, add tag to RemappedTags
   c. Otherwise: skip (non-UI elements untouched)

Important details:
- Use System.Text.Encoding.ASCII.GetBytes for UID encoding (UIDs are always ASCII)
- The walker does NOT skip any tags (unlike UidRemapper.RemapDataset which skips tags based on PS3.15 profile). It remaps ALL VR=UI elements.
- This makes it handle all current and future referencing patterns including RT Plan, Presentation State, SR, KOS, private sequences, etc.
- Follow the netstandard2.0 + net8.0 + net9.0 multi-targeting patterns already in the codebase
- Include full XML doc comments following project conventions
- Namespace: SharpDicom.Deidentification
