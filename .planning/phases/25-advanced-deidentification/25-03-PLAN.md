<objective>
Implement OcrScanner for OCR-based burned-in PHI detection in DICOM pixel data using Tesseract, with full pipeline integration.

Purpose: Burned-in patient information in pixel data (names, dates, IDs overlaid on ultrasound, endoscopy, etc.) cannot be removed by attribute-level de-identification. OcrScanner uses Tesseract OCR to detect text regions, applies allow/deny filtering to distinguish PHI from legitimate annotations (orientation markers, measurement units), and returns results that can drive PixelDataRedactor for automated redaction.

Output: OcrScannerOptions, OcrScanResult, OcrScanner classes with standalone and pipeline usage modes.
</objective>

**OcrScanModality flags enum:**
```csharp
[Flags]
public enum OcrScanModality
{
    None = 0,
    HighRisk = 1,      // US, ES, SC, XC, GM, SM, OP, OPT, ECG, HD
    ModerateRisk = 2,  // XA, RF, MG, DX, CR, PX, IO
    LowRisk = 4,       // CT, MR, PT, etc.
    All = HighRisk | ModerateRisk | LowRisk
}
```

**OcrScannerOptions class:**
- ConfidenceThreshold (float, default 0.6f) -- minimum confidence for center regions
- EdgeConfidenceThreshold (float, default 0.4f) -- lower threshold for edge/corner zones where burned-in text typically lives
- EdgeMarginPercent (float, default 0.15f) -- defines edge zone as 15% from each image edge
- ScanModalities (OcrScanModality, default HighRisk | ModerateRisk)
- Language (string, default "eng")
- TessdataPath (string?, default null -- use bundled data if available)
- PageSegMode (int, default 11 -- PSM_SPARSE_TEXT for scattered overlays)
- MaxDetectionsPerFrame (int, default 200)
- DecompressForOcr (bool, default true) -- when true, decompress encapsulated (compressed) pixel data using CodecRegistry before scanning. When false, skip compressed frames with a warning.
- Allowlist (HashSet of string) -- text patterns that are NOT PHI. Static readonly DefaultNonPhiAllowlist property.
- Denylist (HashSet of string?) -- optional patterns that ARE always PHI (takes precedence over allowlist)

**DefaultNonPhiAllowlist** static property returns a new HashSet containing:
- Single-letter orientation markers: L, R, P, A, S, I, H, F
- Measurement units: cm, mm, m, Hz, kHz, MHz, bpm, ml, mg, kg, dB, sec, min, ms
- Common medical abbreviations: HR, BP, SpO2, ECG, EKG, BMI, BMR, PRF, MI, TI, TIS, TIB, TIC
- Imaging labels: GAIN, DEPTH, FREQ, PWR, DYN, MAP, DR, FR, THI
- Directional: SUP, INF, ANT, POST, LAT, MED, PROX, DIST
- Do NOT include names, dates, or ID-like patterns

**OcrDetection readonly record struct:**
- Text (string) -- detected text
- Confidence (float) -- 0.0-1.0 confidence score
- BoundingBox (RedactionRegion) -- reuse existing RedactionRegion type for coordinates
- FrameIndex (int) -- which frame this detection is from
- IsEdgeRegion (bool) -- whether detection is in edge zone

**OcrScanResult class:**
- Detections (IReadOnlyList of OcrDetection) -- all detections above threshold
- FilteredDetections (IReadOnlyList of OcrDetection) -- detections after allow/deny filtering (these are the PHI candidates)
- TotalFramesScanned (int)
- FramesWithDetections (int)
- ScanDuration (TimeSpan)
- ToRedactionRegions() method -- converts FilteredDetections to List of RedactionRegion for use with PixelDataRedactor

**OcrScanner sealed class (implements IDisposable):**

Constructor(OcrScannerOptions? options = null):
1. Store options (use defaults if null)
2. Check TesseractNativeMethods.tess_available() -- if 0, throw InvalidOperationException("Tesseract OCR is not available. Install the SharpDicom.Codecs native package with Tesseract support.")
3. Create TesseractHandle via tess_create()
4. Initialize with tess_init(handle, options.TessdataPath ?? FindBundledTessdata(), options.Language)
5. Set page segmentation mode via tess_set_page_seg_mode(handle, options.PageSegMode)

**FindBundledTessdata() private static method:**
Look for eng.traineddata in common locations:
- Directory containing the SharpDicom.Codecs assembly + "/tessdata"
- AppContext.BaseDirectory + "/tessdata"
- Environment variable TESSDATA_PREFIX
- Return null if not found (tess_init will fail with descriptive error)

**ScanDataset(DicomDataset dataset) public method returning OcrScanResult:**
1. Check modality against ScanModalities using BurnedInAnnotationDetector risk categories
2. Get PixelDataInfo from dataset
3. Get pixel data element
4. Handle compressed data:
   - If pixel data is encapsulated (compressed), check DecompressForOcr option:
     a. If DecompressForOcr is true (default): Use CodecRegistry to find the appropriate codec for the dataset's Transfer Syntax. Decompress the pixel data to uncompressed format, then scan the decompressed data. After scanning, the caller can choose to re-compress or leave uncompressed.
     b. If DecompressForOcr is false: Log warning and return empty result (caller must decompress first).
   - Use existing CodecRegistry.TryGetCodec() to find codec, then codec.Decode() to get uncompressed pixel data.
5. Determine number of frames
6. For each frame:
   a. Extract frame data using pixel data element's RawValue with frame offset calculation
   b. Call PrepareFrameForOcr() to convert to 8-bit grayscale:
      - 8-bit grayscale: check PhotometricInterpretation, invert if MONOCHROME1 (255 - value)
      - 16-bit grayscale: window/level to 8-bit using Window Center/Width tags or full-range normalization. Invert for MONOCHROME1.
      - RGB (3 samples/pixel): convert to grayscale using luminance formula (0.299R + 0.587G + 0.114B)
      - Other: throw NotSupportedException with descriptive message
   c. Pin the byte array and call:
      - tess_set_image(handle, pinned_ptr, width, height, 1, width) for grayscale
      - tess_recognize(handle)
      - tess_get_detections(handle, results_ptr, maxDetections, out actualCount)
   d. Convert each native TessDetection to OcrDetection:
      - Marshal text from IntPtr via Marshal.PtrToStringUTF8 (NET6+) or manual UTF8 decode (netstandard2.0)
      - Free text via tess_free_text
      - Determine IsEdgeRegion based on bounding box position relative to image dimensions and EdgeMarginPercent
      - Apply confidence threshold: use EdgeConfidenceThreshold for edge regions, ConfidenceThreshold for center
      - Convert confidence from 0-100 (Tesseract) to 0.0-1.0
   e. Call tess_clear(handle) between frames (NOT tess_delete which destroys the instance)
7. Apply allow/deny filtering:
   - For each detection, check if text (trimmed, case-insensitive) matches any allowlist entry
   - Check if text matches any denylist entry (denylist takes precedence)
   - Also filter purely numeric strings by default (measurements like "3.2" are not PHI)
   - FilteredDetections = detections that are NOT in allowlist AND (are in denylist OR are unmatched)
8. Build and return OcrScanResult with timing via Stopwatch

**Dispose():**
- Dispose TesseractHandle (calls tess_delete via SafeHandle)

Important implementation details:
- Use `unsafe` blocks with `fixed` for pinning byte arrays to pass to native code
- Use try/finally to ensure tess_free_text is called for every text pointer
- Handle the case where tess_recognize fails (returns non-zero) -- add warning to result, skip frame
- OcrScanner should be thread-safe for single-threaded use but NOT for concurrent access (document this)
