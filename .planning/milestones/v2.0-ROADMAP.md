# Milestone v2.0: Network, Codecs & De-identification

**Status:** SHIPPED 2026-02-02
**Phases:** 10-14
**Total Plans:** 38

## Overview

Full DICOM networking stack, comprehensive image codec support (pure C# and native), and PS3.15-compliant de-identification. This milestone transforms SharpDicom from a file I/O library into a complete DICOM toolkit.

## Milestone Summary

**Key Decisions:**

- 13-state association machine per PS3.8 (Sta1-Sta13 numbering)
- IAsyncEnumerable for Q/R streaming (memory-efficient for large result sets)
- Loeffler DCT algorithm (11 muls, 29 adds - theoretical minimum)
- Zig cross-compilation (single toolchain for 6 targets)
- UUID-derived UIDs for de-identification (no registered root needed)

**Issues Resolved:**

- DicomClient state machine bug (AAssociateRequest before TransportConnectionConfirm)
- DicomServer AssociationOptions timing (read A-ASSOCIATE-RQ first)
- CA2255 warning for ModuleInitializer (explicit registration preferred)

**Technical Debt Incurred:**

- Streaming C-STORE SCP uses simplified parser (not full roundtrip fidelity)
- HTJ2K codec implementation deferred to Phase 18
- JPEG-LS full implementation deferred to Phase 18
- TLS support deferred to v3+
